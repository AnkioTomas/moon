备份与恢复

打包月读数据目录（书库、笔记、进度、统计、全部配置），不含日志和缓存。配置里有各书源登录信息、Cookie、密钥和锁屏密码，请妥善保管备份文件。恢复会覆盖设备上的月读数据并自动重启 KOReader。
