# 第三方组件

`classes.dex` 来自 [titandrive/koboard](https://github.com/titandrive/koboard) v0.6.5
（commit `d49f0981cdafd8a3e387a7f9e6be5d45f88cea08`），用于在 Android 上提供一个带
`InputConnection` 的 `View`，把系统输入法上屏的文本通过文件快照交给 Lua。

- 上游源码：`java/`（见 `java/upstream.md` 的记录与文件哈希）
- 构建脚本：`tools/build_android_ime_dex.sh`
- 产物哈希：`classes.dex.sha256`（构建后校验）
- 许可：MIT（上游 README 声明；`java/LICENSE` 保留原文）
