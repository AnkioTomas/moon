# 月读服务书源

源 ID：`moon`，整本书模式。

## 配置

在「设置 → 书库 → 月读服务」填写服务器地址和长期令牌。地址为月读服务端地址；令牌由服务端提供。两项都填写后源才算已配置。令牌失效时需要重新填写，不会自动续期。

## 功能

- 分页读取服务端书架并同步到本地；本地删除先隐藏并记墓碑，之后的同步才向服务端删除。
- 按书籍 `filename` 下载整本书，验证文件后登记到本地工作目录；支持 EPUB、PDF、CBZ、CBR、MOBI、AZW、AZW3 和 TXT。未识别扩展名的下载按 EPUB 文件名保存。
- 尽可能读取服务端封面。
- 阅读进度、划线／书签及阅读统计可双向同步。进度保存章节、页码、偏移和 locator；注解按整本书集合上传。

## 限制

- 服务端没有加入书架接口，本地新增成员不会上传到月读服务。
- 本地书架变化优先保存；网络失败时待同步数据留在本地，后续联网再推送。
- 进度坐标能否在不同设备间精确恢复取决于文件和 locator；文件内容或排版改变时可能只能按百分比恢复。
- 统计拉取使用服务端账户的完整快照；不同设备使用同一账户时，服务端数据会成为同步来源之一。

## 实现

HTTP 接口和鉴权在 `client.lua`，wire 字段映射在 `mapper.lua`，源适配在 `init.lua`。配置保存在 `utils.settings` 的 `moon` 源分区。
