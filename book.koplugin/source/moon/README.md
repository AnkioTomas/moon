# 月读服务

| 能力 | 是否支持 | 备注 |
| --- | --- | --- |
| 服务连接 | 支持 | 填写月读服务端地址和长期令牌；令牌不自动续期 |
| 书架拉取 | 支持 | 分页读取服务端书架 |
| 加入远端书架 | 不支持 | 本地新增成员不上传 |
| 删除远端书籍 | 支持 | 本地先清缓存、留墓碑，服务端确认后清记录 |
| 整本下载与阅读 | 支持 | EPUB、PDF、CBZ、CBR、MOBI、AZW、AZW3、TXT |
| 封面 | 部分支持 | 取决于服务端是否提供 |
| 阅读进度同步 | 支持 | 双向同步；文件或排版变化时可能只能按比例恢复 |
| 划线与书签同步 | 支持 | 按整本书集合双向同步 |
| 阅读统计同步 | 支持 | 使用服务端账户快照 |
| 书评、章评、段评与回复 | 不支持 | 当前服务契约未接入；个人注解不是他人评论 |
| 离线阅读 | 支持 | 已下载文件和本地记录可用；同步与下载需要联网 |
