# 得到

| 能力 | 是否支持 | 备注 |
| --- | --- | --- |
| 手机短信登录 | 支持 | 中国大陆手机号；未注册号码可能自动注册，发送前需确认协议 |
| 短信安全验证 | 部分支持 | 手机访问远程网页完成官方易盾滑块；触发验证后的完整续发流程未实测 |
| App 扫码登录 | 已实现，未实测 | 得到 App 扫码，不是微信扫码 |
| 浏览器登录与 Cookie 导入 | 支持 | 保留官网登录及粘贴入口 |
| 设备密码登录 | 不支持 | 未接入 |
| 书架拉取 | 支持 | 分页读取“已购”电子书集合，过滤课程、听书和自上传内容 |
| 加入与移出远端集合 | 已实现，未实测 | 本地先生效，再同步；移出不撤销购买 |
| 搜索与分类书城 | 支持 | 动态分类、子分类、排序和筛选，支持后续页，默认聚合约 60 本 |
| 详情与目录 | 支持 | 目录需阅读 token；真实登录后的读取尚待验证 |
| 正文与全本缓存 | 已实现，未实测 | SVG 解密与文字还原，需有效阅读权限；真实登录阅读链路未验证 |
| 离线阅读 | 支持 | 仅已成功缓存的目录与正文 |
| 阅读进度同步 | 部分支持 | 仅章节位置，无精确章内位置；真实远端写入未实测 |
| 笔记与统计同步 | 不支持 | 仅本地保存 |
| 整书书评 | 支持 | 读取真实书评列表，支持客户端分页去重 |
| 章评、段评与回复 | 不支持 | 未接入可验证的公共评论接口；原版笔记及笔记回复不是章／段评 |
| 评论写操作 | 不支持 | 不发评、不点赞、不删评 |
| 账号切换 | 部分支持 | 已绑定账号时拒绝直接换号；须先退出清理，旧配置迁移隔离有限 |
