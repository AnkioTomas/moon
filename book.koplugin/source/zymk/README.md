# 知音漫客

| 能力 | 是否支持 | 备注 |
| --- | --- | --- |
| 密码与短信登录 | 支持 | 保存前兑换／校验账号；短信触发点字验证时由用户完成 |
| 手动 Cookie 导入 | 支持 | 只保存校验后的必要会话字段 |
| 微信、App 扫码与浏览器扩展登录 | 不支持 | 未提供对应入口 |
| 远端书架拉取 | 支持 | 登录后读取完整收藏并对账 |
| 远端收藏新增与移出 | 不支持 | 未接入上行；本地删除留墓碑，不删除官网收藏 |
| 搜索 | 支持 | 聚合后续页，最多约 200 本 |
| 分类书城 | 支持 | 完整分类库、动态标签及多种排序；不提供未经验证的资费筛选 |
| 详情与目录 | 支持 | 知音漫客作品跳转官方看漫画，保持章节顺序和身份 |
| 免费漫画阅读 | 支持 | 下载页图为 CBZ，由 KOReader 阅读 |
| 已购与 VIP 漫画 | 不支持 | 未实现账号阅读权限；标价章节提示未购买 |
| 章节与全本缓存 | 支持 | 支持预取、范围和后台缓存，失败不生成成功 CBZ |
| 离线阅读 | 支持 | 已缓存目录、CBZ 和本地位置可用 |
| 进度、笔记与统计同步 | 不支持 | 仅本地保存；远端进度写入不能回读确认 |
| 整书书评 | 部分支持 | 详情仅最新第一页；传输可续页，界面没有后续页入口 |
| 每话章评与段评 | 不支持 | 当前 Web 协议未找到可验证接口 |
| 评论回复与写操作 | 不支持 | 未接入 |
| 账号切换 | 部分支持 | 身份不同须先退出清理旧本地数据，未同步记录会丢失 |
