# QQ阅读

| 能力 | 是否支持 | 备注 |
| --- | --- | --- |
| 扫码登录 | 已实现，未实测 | 阅文扫码，保存前校验账号 |
| 浏览器登录与 Cookie 导入 | 支持 | 手动粘贴及扩展回传；扩展完整握手未实测 |
| 设备密码与短信登录 | 不支持 | 未接入 |
| 书架拉取 | 支持 | 分页读取，坏响应不会当成空书架 |
| 书架新增与移出 | 已实现，未实测 | 本地先生效，再同步上行 |
| 搜索与榜单 | 支持 | 搜索最多 200 本；男生、女生、出版榜单默认聚合 60 本 |
| 分类书城 | 部分支持 | 已接动态分类及筛选，但源站列表间歇为空，尚未稳定通过实测 |
| 详情与目录 | 支持 | 保留书号、章节 ID 和目录缓存 |
| 免费正文 | 支持 | 免费章可读，未购预览不当作正文缓存 |
| 已购与会员正文 | 已实现，未实测 | 沿官网权限、解码和字体还原流程 |
| 章节与全本缓存 | 支持 | 缓存正文和目录可离线阅读 |
| 阅读进度同步 | 部分支持 | 仅章节 ID，无章内比例；书已离架时不借上传进度重新加架 |
| 笔记与统计同步 | 不支持 | 仅本地保存 |
| 整书书评 | 部分支持 | 首批预览；官网未返回有效后续游标，未接完整分页 |
| 章评与段评 | 不支持 | 当前 Web 协议未找到可验证接口 |
| 评论图片、回复与写操作 | 不支持 | 尚未接入 |
| 账号切换 | 部分支持 | 同账号可续期；换号须确认清理旧本地数据，未同步记录会丢失 |
