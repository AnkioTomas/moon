# QQ阅读

使用电脑官网 `https://book.qq.com` 的 Web 协议；不使用 App 私有接口。

## 能力与边界

- **登录**：阅文扫码、电脑 Cookie 粘贴及浏览器扩展回传。扫码参数采用官网 SDK 的 `appid=1450000220`、`areaid=1`；第三方扫码域不携带书源 Cookie。插件尚未实现密码／短信验证码登录。
- **书架**：分页拉取、加入和删除上行沿用现有书架同步。详情用于补齐简介。坏响应或重复分页明确失败，不能作为空书架清理本地记录。
- **书城**：男生／女生／出版榜单；已接官网动态分类及子分类、状态、价格、字数、更新时间和排序，但分类尚未稳定通过实测，见下文限制。分类每批默认最多 60 本，搜索从 JSON 接口聚合最多 200 本；界面每页数量由宿主决定。保留旧 `rank:<榜单名>` 和 `cate:<分类号>` 节点及缺省男生热门榜。
- **阅读**：目录与免费正文；已购／会员授权章节沿官网 Fock 与乱序字体流程解码。未购预览不能当正文缓存。每次章节操作固定 Cookie 快照，带 `fuid` 重读后再次检查权限，关闭／取消后忽略迟到响应。
- **评论**：详情页整书书评，含作者、标题、正文和时间。2026-11-07 实测官网返回 15/32 条且 `cursor=""`，登录后也相同，因此标为预览，不宣称完整分页。图片和完整回复尚未接入。已检查公开阅读页脚本；该 Web 协议未找到可验证的章评／段评接口，不将整书书评复制到每章，也不推断 App 无此能力。
- **进度**：远端只记录章节 ID，没有章内比例；拉取时按章节索引计算全书比例。书已离开远端书架时不上传进度，也不借上传进度重新加架。笔记和阅读统计仅在本地，本次未找到可验证的远端同步接口。
- **离线**：保留已有目录、章节、进度及笔记；缓存内容可读，本地改动先落盘。未缓存正文、书城和登录依赖网络，不伪造离线成功。

## 主要接口

成功为 JSON `code=0`；`code=-4` 为登录失效。登录重定向／401 也处理为失效，暂时网络故障不清登录；旧 Cookie 的迟到失败不能注销新登录。

| 用途 | 方法／路径（相对 `/api`） | 关键字段 | 登录 |
| --- | --- | --- | --- |
| 账号校验 | GET `/user/homepage` | `data`；该接口不返回稳定账号 ID | 是 |
| 书架 | GET `/bookshelf/query` | `pageNo,pageSize`；`topBookList,bookList,hasNext` | 是 |
| 加入／删除 | POST `/bookshelf/add`、`/bookshelf/delete` | JSON `bid`／`bids` | 是 |
| 搜索 | GET `/booksearch/query` | `keyWord,pageNo,pageSize`；`bookList,hasNext` | 否，不带账号 Cookie |
| 分类元数据 | GET `/category/<条件>` | `categoryId2-categoryId3-finishStatus-priceStatus-words-updateTime-orderBy-pageNo`；`categoryList,params` 与筛选项 | 否，不带账号 Cookie |
| 分类书卡 | 官网 `/book-cate/<条件>` | SSR HTML 书卡，条件同上 | 否，不带账号 Cookie |
| 榜单 | 官网 `/book-rank/<榜单>/cycle-1[-<页>]` | 服务端 HTML 书卡 | 否，不带账号 Cookie |

| 正文 | GET `/book/read` | `bid,cid,fuid?`；`chapterVipFlag,authStatus,encrypt,fontEncrypt,fontResponse` | 免费可匿名，已购需登录 |
| 解码材料 | GET `/user/index/piracy` | `fkp,fuid`；跟同次重读身份绑定 | 是 |
| 整书书评 | GET `/bookcomment/list` | `bid,cursor?`；`comments,commentCount,cursor` | 否，不带账号 Cookie |

## 本地与账号边界

本地 sqlite 与文件是唯一真相；新增、进度和删除先在本地生效并标脏，再由同步上行。删除先清缓存和留墓碑，远端确认后才移除本地身份；失败保留墓碑重试，不因坏拉取响应复活或清空书架。

官网登录 SDK 将同一 `ywGuid` 写入 `ywguid` 和 `uid`。成功校验候选 Cookie 后，以该数字 ID 区分续期和换号；缺失或两个别名冲突则拒绝保存。旧配置没有 ID 时先校验原 Cookie，无法确认旧账号须先退出，不能按昵称或 Cookie 是否变化猜账号。

同账号续期保留数据。真正换号先确认：正常结束旧阅读会话、取消旧任务、暂时隔离旧凭据，再清理本源本地书架／进度／笔记／缓存（包含未同步记录），最后保存新账号；不删除远端书架、不把清库操作推到新账号。取消、校验失败或清理失败不覆盖旧有效账号。
