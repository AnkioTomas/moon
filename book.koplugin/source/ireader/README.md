# 掌阅

## 能力与边界

插件使用掌阅电脑 Web 与官方手机 Web，不使用 App 私有接口。登录保存电脑站的 `usr` 与 `zysid`；不保存密码，也没有短信验证码登录。电脑站用 `_zypps` Cookie 保存会话，浏览器登录 / 粘贴 Cookie 会从中解析 `usr/zysid`，校验书架接口通过后才写入。

| 功能 | 当前实现 |
| --- | --- |
| 登录 | App 扫码、官网浏览器登录 / 粘贴 Cookie（`_zypps`）；创建二维码、等待授权、校验候选会话；成功校验后才保存 |
| 书架 | 拉取电脑站书架，上传本地新加入的书；过滤文件夹和本机上传书 |
| 删除 | 本地清缓存并留墓碑；当前未接入可验证的远端删除接口，不声称网站或 App 不支持删除 |
| 搜索与书城 | 手机站搜索；从官网动态读取男生、女生、出版的分类、排序与筛选，按调用方 limit 聚合后续页 |
| 目录与正文 | 电脑站目录分页、按章打开、预取和全本缓存；HTML 中二十个补充私用字码还原为常用字，远程插图下载到本地 |
| 付费章节 | 已购才允许缓存；未购在阅读时显示临时购买提示，不能把提示保存成正文缓存；插件不购买或充值 |
| 进度 | 上传章节位置、读取章节位置；没有章内精确进度。`readPercent` 是官网 TXT/PDF 的比例，不能用在本源按章阅读 |
| 评论 | 读取手机 Web 整书书评首屏，详情页复用段评卡片列表；只在本地翻阅已加载内容，不续拉官网后续页。该 Web 协议未找到可验证的章评、段评或回复分页接口 |
| 笔记与统计 | 本地保存；没有远端笔记或统计同步实现。官网有阅读时长上报路径，不等于插件已经接入 |
| 离线 | 已缓存章节及目录可读；旧目录格式离线继续使用。未缓存正文、搜索、分类与扫码依赖网络，失败须有回调或提示 |

官网“其他”筛选将免费、特价、完结和 VIP 放在同一组，互斥，不能任意组合资费与连载状态；出版频道没有“完结”。频道切换保留仍有效的排序，重选该频道实际分类，并清除不支持的状态。分类、排序和状态复用书城分组折叠菜单。兼容原有 `h5_ch_male`、`h5_ch_female`、`h5_ch_publish` 节点。

## 协议概览

账号请求使用 `https://api-pc.zhangyue.com`，正文使用 `https://pc.ireader.com`，公开搜索、分类和书评使用 `https://m.zhangyue.com`。手机书城请求不附带电脑账号凭证。电脑请求携带官网运行配置的 `p29/p2/p3/p4/p33`。

| 用途 | 方法与路径 | 关键字段与响应 | 登录 |
| --- | --- | --- | --- |
| 二维码 | GET `/bookstore/open/user/qrcode/get` | `code=0` 的 body 为登录码；二维码内容 `web_login:<码>` | 匿名，不缓存 |
| 扫码轮询 | GET `/bookstore/open/user/qrcode/result` | `code=<码>`；`30059` 等待；成功 body 的 `name/session_id` 为账号与会话 | 匿名，不缓存 |
| 校验、书架 | GET `/bookstore/open/cloud/bookshelf/list` | `usr/zysid`；body 含 `data/current_version`，空壳成功不是有效书架 | 是 |
| 新加入架 | POST `/bookstore/open/cloud/bookshelf/upsert` | multipart `usr/current_version/type=1/data`；官网常量 `0` 成功、`100011` 已在架，本次未做账号写入实测 | 是 |
| 详情 | GET `/bookstore/open/book/detail` | `book_id`；名称、作者、封面、`fee_unit` | 是 |
| 目录 | GET `/bookstore/open/book/chapter/web/list` | `book_id/page/size=50`；`list/page.totalPage` | 是 |
| 正文 | GET `/nsr/chapter-content` | `book_id/chapter_id/is_whole_book`；`bookContent` 与 `charging_info.is_buy`；部分常用字使用 `U+F0000–F0009`、`U+F0010–F0019` | 是 |
| 正文插图 | GET 正文 `img.src` 给出的 CDN URL | 保留 URL 参数并解码 `&amp;`；只带官网 Referer，不附带 `usr/zysid` 或 Cookie；下载后改写为 `images/<内容哈希>.<格式>` | 不发送账号凭证 |
| 读进度 | GET `/bookstore/open/cloud/book/getProgress` | `bookIds`；按书 ID 返回 `readProcess.chapterId` | 是 |
| 写进度 | POST `/bookstore/open/cloud/book/progress` | JSON `bookId/usr/deviceName/updateTime/readProcess`；目录 UID 减一写入 `chapterId` | 是 |
| 分类配置 | GET `/category/<频道>/<分类>?currentPage=1` | HTML 中实际分类链接、`parentId/categoryId`、`data-order/data-status` | 否 |
| 分类分页 | GET `/category/<频道>/<分类>` | `isAjax=1/currentPage/pageSize/order/status`；`code=0/html/body.current_page/body.page_total` | 否 |
| 搜索 | GET `/search` | `keyWord`；HTML 书籍卡片 | 否 |
| 整书书评 | GET `/comment/<书ID>` | 首屏 HTML 的 `sns_commentlist`：作者、正文、时间与评分；只请求一次，不使用 AJAX 分页，只绑定书 ID | 否 |

电脑 JSON 封套通常为 `{ code, msg, body }`；`body` 可能再编码为 JSON 字符串。`600001` 为失效，匿名 `100001` 为未登录。旧会话的迟到响应不能标记新会话失效或清除新会话的失效状态。临时扫码会话的校验也不改变已保存账号。

`/bookstore/open/user/info` 虽存在于公开脚本，本次匿名调用返回 `404 Route Not Found`，不能用它假装完成账号校验；插件用实际书架结构校验。

## 本地与同步

本地 sqlite、目录和章节文件是唯一真相。加入书架先写本地并标脏，后台书架同步负责上传；失败保留脏行。删除先清缓存，再写墓碑，书架立即隐藏，远端快照不会复活它。没有远端确认删除时不撕墓碑。进度先落本地，写远端失败不能伪造成功，也不回滚本地阅读结果。

沿用书籍 ID、目录 UID、章节索引及目录缓存版本。同账号换会话可以续期；依据扫码返回的稳定 `usr` 判定换号，不按昵称或会话字符串判断。不同账号拒绝直接覆盖，用户须先使用现有“退出登录”确认流程：停止同步、清凭证、清本地书架/进度/笔记/缓存，再登录其他账号。退出会丢弃未同步的本地记录，不能静默清理或把旧账号墓碑上传到新账号。

## 第一轮协议核对与未验证项

核对日期：**2026-11-07**。

- 官网公开脚本确认电脑端扫码、书架、目录、正文、进度的路径与参数；章式进度写 `chapterId`，TXT/PDF 才写 `readPercent`。
- 真实公开分类页确认男生 11 类、女生 8 类、出版 42 类，三频道均有 3 种排序；出版不提供完结筛选。真实分类第 2 页返回有效 JSON 及不同的书籍，不能把频道推荐第一页当完整书城。
- 有书评的公开页面返回 14 页；仅传整本书 ID，不能据此伪造章评或段评。
- 独立联网模拟器实测三频道各聚合 25 本、都市评分/免费筛选 15 本、搜索 20 本；实际书城页加载 60 本，8 本/页，共 8 页。截图核对两行筛选、分类/排序/状态菜单、翻页与封面。
- 真实二维码创建和轮询返回 `30059` 等待授权，扫码窗口可显示并关闭；没有扫码确认或保存账号。临时断网后的搜索在下一 UI tick 明确失败，恢复原网络方法后公开静态接口的真实无缓存请求返回 HTTP 200。
- 后续一次分类首页请求返回官网验证码 HTML，插件明确报“响应无效”，未包装为空列表；本次没有绕过验证码，也不承诺书城永不触发站点验证。
- 专项离线用例覆盖匿名扫码、候选校验、换号拒绝、旧会话竞态、取消、坏响应、中间页失败、去重、旧节点、离线旧目录和章节进度。
- 本次未导入真实账号，不进行远端增删或进度写入；扫码确认、账号书架同步、免费/已购电脑正文、未购实际响应、全本缓存及断网重开不能据单测宣称实测通过。密码和验证码不是本插件实现的登录方式。
- 远端增删和进度成功码目前依据官网脚本及离线用例，仍需用户具体授权后写入测试位置/测试书并读回确认，才能声称真实同步成功。
- 本轮掌阅 6 个 spec、175 条断言通过，掌阅源码及测试定向 LuaLS 无告警。全量测试另有既有翻译字典残留键失败；掌阅变更前后均为 16 项，本次未改动无关字典。全仓 LuaLS 已发现其他功能告警，因检查耗时过长中止，不声称全仓零告警。

## 正文反馈修复（2026-11-07）

- 用户日志与官网公开书目对上同一本书、同一章节。只读检查已登录独立预览的免费章节响应，确认正文是有效 UTF-8，但部分常用字是补充私用区 A 字符；不是缺普通中文字体，也不是整个正文需要解密。
- 官网阅读器公开脚本强制使用 `FZYouH_509R_V1.10.ttf`。核对该字体实际字形后，将二十个字码映射成普通 Unicode，不下载或安装此字体到用户设备。新出现的未知私用字码明确报错，不把问号写成成功缓存。
- 按章打开、阅读预取与全本缓存都复用 `source.assets` 下载插图。同一 URL 去重，内容寻址复用；下载失败或收到非图片响应时明确失败，取消正文或插图阶段后都不再交出迟到的成功结果。
- 已就绪的旧章节在本地原地还原字码，保留 HTML 节点、书籍身份、文件路径和 sidecar；原子替换失败保留旧文件，不清库、不清笔记或进度。旧缓存仍引用远程插图的章节需要联网重新补齐资源；已落地的新正文与图片不依赖官网字体或网络。
- 本次没有导出或复制账号凭证，没有写远端进度、增删书架或购买。
- 真实反馈章节中 176 处私用字码还原后剩余 0 处，对照截图的原句匹配；正文共 46 个 `img` 标签，抽检原始插图 CDN 返回有效图片。这里只验证了一张原图，不声称真实全本插图或已购章节已经逐一实测。
- 另建空账号、空书库的独立模拟器，用合成正文和本机图片服务跑实际 HTTP、源侧落盘与 CREngine 排版：普通字体、禁用内嵌字体/样式时，二十个字与插图均可显示。停掉图片服务并断网后，走 `openBookAsync` 原地还原旧缓存，再用新文档路径重新加载，文字与图片仍可见、HTTP 调用为 0；没有把联网预取任务当作离线开书。
- 最终掌阅与公共插图回归共 8 个 spec、247 条断言通过，掌阅源码、用例和相关翻译共 15 个 Lua 文件定向 LuaLS 无告警。本次没有重新执行全仓测试，也没有导入账号实测全本缓存或远端写操作；第一轮的全仓已知失败仍按上一节记录。
