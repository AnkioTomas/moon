# 掌阅

| 能力 | 是否支持 | 备注 |
| --- | --- | --- |
| App 扫码登录 | 已实现，未实测 | 校验候选会话后保存 |
| 浏览器登录与 Cookie 导入 | 支持 | 从电脑站 Cookie 解析必要会话并校验 |
| 设备密码与短信登录 | 不支持 | 其他方式可在官网完成后导入 Cookie |
| 书架拉取 | 支持 | 过滤文件夹和本机上传书 |
| 加入远端书架 | 已实现，未实测 | 本地先生效，后续同步上传 |
| 移出远端书架 | 不支持 | 没有已接入的删除接口；本地清缓存并保留墓碑 |
| 搜索与分类书城 | 支持 | 男生、女生、出版；动态分类、排序与筛选，支持后续页 |
| 目录与正文 | 支持 | 分页目录、按章阅读、特殊字码还原及插图本地化 |
| 已购正文 | 已实现，未实测 | 以服务端权限为准；未购提示不计入正文缓存 |
| 章节与全本缓存 | 支持 | 支持预取；插图下载失败不算正文缓存成功 |
| 离线阅读 | 支持 | 已缓存正文和本地插图可读；旧远程插图需先联网补齐 |
| 阅读进度同步 | 部分支持 | 仅章节位置，无精确章内进度；真实写后回读未实测 |
| 笔记与统计同步 | 不支持 | 仅本地保存 |
| 整书书评 | 部分支持 | 仅手机 Web 首屏；本地翻阅已加载条目，不续拉 AJAX 页 |
| 章评、段评与回复 | 不支持 | 当前 Web 协议未找到可验证接口 |
| 评论写操作 | 不支持 | 不发评、不点赞、不删评 |
| 账号切换 | 部分支持 | 同账号可续期；换号须先退出清理旧数据，未同步记录会丢失 |
