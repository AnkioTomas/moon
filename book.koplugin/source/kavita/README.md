# Kavita 书源

源 ID：`kavita`，整本书模式。书架中的每一行代表 Kavita 的一个 series；多卷系列在打开时选择卷，进度按卷分别保存。

## 配置

在「设置 → 书库 → 账号 → Kavita」填写服务器地址和 API Key，并选择要同步的书库。连接测试会检查服务器版本；实现要求 Kavita 0.9 或更新版本。更改服务器或书库后，本地书架缓存会失效并重新同步。

## 功能

- 从所选书库分页读取 series 书架；Kavita 书架只读，月读不会向服务器加入或删除书籍。
- 下载并打开 EPUB、PDF、CBZ 等支持格式；多卷系列可选择具体卷。目录缓存可在离线时使用。
- 同步阅读进度：EPUB 尽量使用 spine 与页面锚点，固定版式使用页码；设置中的进度心跳可让阅读中的会话时长记入 Kavita。
- 同步 EPUB 划线与备注；非 EPUB 格式不走 Kavita 注解接口。
- 拉取 Kavita 阅读历史作为本地统计快照；本地统计上报调用会被确认，但不会向服务器创建阅读历史。
- 按书库／系列补全作者、简介等元数据，并读取远端封面。
- 使用 kamare 增强版的漫画在线阅读与缓存队列。没有可用增强接口时，CBZ 可回退为下载后由 KOReader 阅读；图片目录格式不能按此方式回退。

## 漫画缓存

安装并启用与服务器兼容的 `kamare.koplugin` 增强版后，书源可将缓存请求交给 kamare 管理，并显示缓存状态。官方版或旧版接口不一定提供离线缓存、按章清理或阅读进度恢复能力；设置页会显示探测到的安装状态。kamare 负责其缓存队列和漫画查看器，月读不实现另一套漫画下载器。

## 限制与同步语义

- 书架只拉取，不支持把月读本地书架增删推回 Kavita；本地删除留在月读墓碑中，后续书架对账不会让它复活。
- 远端阅读统计按 Kavita 历史快照导入；月读本地统计不会被上传为 Kavita 阅读会话。
- 注解同步目前针对 EPUB；坐标定位依赖本机 EPUB 内容，无法定位时不会把无效锚点强行写入服务端。
- Kavita 返回的 EPUB 进度粒度可能只有 spine；这种情况下优先保留本机同一 spine 内更精确的位置。
- 漫画缓存、缓存清理、队列状态及离线能力受 kamare 版本与接口能力影响。

实现位于 `init.lua`、`client.lua`；进度坐标、注解、统计和漫画缓存适配分别在 `position.lua`、`annotation.lua`、`stats.lua`、`cache.lua`。
