# Kavita

| 能力 | 是否支持 | 备注 |
| --- | --- | --- |
| 服务连接 | 支持 | Kavita 0.9 或更新版本；填写地址、API Key 并选择书库 |
| 书架拉取 | 支持 | 分页读取系列；多卷系列打开时选择卷 |
| 加入与移出远端书架 | 不支持 | 书架只读；本地删除不操作服务器藏书 |
| 详情与封面 | 支持 | 读取书库、系列及作者等元数据 |
| 整本下载与阅读 | 支持 | EPUB、PDF、CBZ 等 KOReader 支持的格式 |
| 漫画在线阅读与缓存 | 部分支持 | 依赖兼容的 kamare 增强版；无增强接口时 CBZ 可下载阅读，图片目录不能同样回退 |
| 阅读进度同步 | 支持 | 按卷保存；EPUB 使用 spine／锚点，固定版式使用页码 |
| 划线与备注同步 | 部分支持 | 仅 EPUB；依赖本地内容和坐标定位 |
| 阅读统计同步 | 部分支持 | 拉取历史快照；进度心跳可记入会话时长，不上传本地统计集合 |
| 整书书评 | 已实现，未实测 | 系列级书评，卷共享所属系列缓存；受服务器版本、Kavita+ 及外部评价权限影响 |
| 章评与段评 | 不支持 | 未接入可验证的读取接口；服务器存在章节评价模型，不等于插件已接入 |
| 评论回复与写操作 | 不支持 | 不发评、不改评分 |
| 离线阅读 | 支持 | 已下载文件及目录可用；漫画缓存取决于 kamare |
