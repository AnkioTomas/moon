# 本地书籍书源

源 ID：`local`，整本书模式。支持扫描设备上的书籍目录，或将 WebDAV 作为远端书库使用。

## 本地目录模式

在「设置 → 书库 → 本地书籍 → 本地书库目录」选择目录。书架同步会扫描目录中的可识别书籍，将文件路径作为书籍身份；改名或移动文件时，内容相同的文件可沿用原书身份及其阅读数据。扫描不打开每本书，之后会在后台补封面和元数据。

可开启「按文件夹分类」：第一层子目录作为分类、第二层作为系列。关闭后目录不再覆盖分类／系列，用户可以手动编辑书目元数据。本地书籍支持修改展示信息、元数据补全、书城下载导入和书籍移动。

纯本地目录没有远端：进度、笔记和统计保存在本机，不会产生云端同步。

## WebDAV 模式

配置 WebDAV 地址、用户名、密码和远端目录后，源使用 WebDAV 中的书籍与 `.Moon+` 数据文件进行同步。书籍按需下载到本地后打开；本地书架、书籍文件（可关闭上传）、进度、笔记和统计可按实现写回 WebDAV。WebDAV 配置页提供读写测试，会写入、读回并删除一个测试文件。

WebDAV 下书籍文件上传默认开启；关闭「上传本地书到 WebDAV」后仍可同步进度、笔记和统计，但本地书文件不会上传。进度的精确位置保存在附加数据中；若其他客户端改写兼容进度文件，月读会回退使用可用的百分比位置。

## 删除与离线

- 本地目录模式：删除本地文件并清理 KOReader sidecar；目录扫描据此更新书架。
- WebDAV 模式：本地先隐藏书籍并清理本地缓存，再由后续同步处理远端删除；网络失败时本地变化保留待重试。
- 已缓存的书可离线打开；未缓存的 WebDAV 书需要联网下载。

实现分布在 `scan.lua`（扫描、导入、移动）、`webdav.lua`（WebDAV 书目与文件）、`remote_data.lua`（进度、统计和笔记），入口和模式选择在 `init.lua` 与 `client.lua`。
