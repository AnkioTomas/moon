# 本地书籍书源

源 ID：`local`，整本书模式。支持扫描设备上的书籍目录，或将 WebDAV 作为远端书库使用。

## 本地目录模式

在「设置 → 书库 → 本地书籍 → 本地书库目录」选择目录。书架同步会扫描目录中的可识别书籍，将文件路径作为书籍身份；改名或移动文件时，内容相同的文件可沿用原书身份及其阅读数据。扫描不打开每本书，之后会在后台补封面和元数据。

可开启「按文件夹分类」：第一层子目录作为分类、第二层作为系列。关闭后目录不再覆盖分类／系列，用户可以手动编辑书目元数据。本地书籍支持修改展示信息、元数据补全、书城下载导入和书籍移动。

纯本地目录没有远端：进度、笔记和统计保存在本机，不会产生云端同步。

## WebDAV 模式

配置 WebDAV 地址、用户名、密码和远端目录后，源按「同步风格」使用其中一种布局。书籍按需下载到本地后打开；本地书架、书籍文件（可关闭上传）、进度、笔记和统计可按实现写回 WebDAV。WebDAV 配置页提供读写测试，会写入、读回并删除一个测试文件。风格之间不互相迁移，换风格等于换一套远端目录。再加一种风格只在 `layout.lua` 登记一条布局。

- 静读天下（缺省）：书籍在远端目录下（可带子目录），书目是 `.Moon+/books.sync`，进度是 `.Moon+/Cache/<文件名>.po`（章、字符偏移、百分比）。直接覆盖，上传前不读远端。开书按章号和字符偏移落地；百分比只在没有坐标时使用，显示的百分数变了才算不同。
- Legado：书籍在 `books/`（子目录保留，阅读可以进目录打开），没有书目文件，目录里的书文件就是书架。进度是 `bookProgress/<书名>_<作者>.json`（`durChapterIndex` 从 0 计，还要加上目录第一项之前的卷首页；`durChapterPos` 是章内字符数），文件名规则与阅读 `AppWebDav.getProgressFileName` 一致。封面不上传。笔记和统计仍写在 `.Moon+/`，阅读不读它们。

WebDAV 下书籍文件上传默认开启；关闭「上传本地书到 WebDAV」后仍可同步进度、笔记和统计，但本地书文件不会上传。

## 删除与离线

- 本地目录模式：删除本地文件并清理 KOReader sidecar；目录扫描据此更新书架。
- WebDAV 模式：本地先隐藏书籍并清理本地缓存，再由后续同步处理远端删除；网络失败时本地变化保留待重试。
- 已缓存的书可离线打开；未缓存的 WebDAV 书需要联网下载。

实现分布在 `scan.lua`（扫描、导入、移动）、`webdav.lua`（WebDAV 书目与文件）、`remote_data.lua`（进度、统计和笔记），入口和模式选择在 `init.lua` 与 `client.lua`。
