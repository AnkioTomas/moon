# 塔读

| 能力 | 是否支持 | 备注 |
| --- | --- | --- |
| 微信扫码登录 | 支持 | 保存前校验账号，失败或取消不覆盖旧登录 |
| 浏览器登录与 Cookie 导入 | 支持 | 官网完成登录后手动粘贴或扩展回传 |
| 设备密码、短信与登录验证码 | 不支持 | 交由官网完成，不跳过验证码 |
| 书架拉取 | 支持 | 登录后分页读取 |
| 书架新增与移出 | 已实现，未实测 | 本地先生效，写后回读确认；失败保留脏行或墓碑 |
| 搜索与分类书城 | 支持 | 动态频道、分类、状态、字数和排序，默认聚合 60 本 |
| 详情与目录 | 支持 | 保留章节 ID、顺序及旧缓存 |
| 普通与特殊字体正文 | 支持 | 字形还原为普通文字；未知字形明确失败 |
| App 扫码阅读授权 | 支持 | 受限章节显示官网二维码，确认后重新核对权限；不等同账号登录 |
| 图片式正文 | 不支持 | 未接入 |
| 付费阅读 | 部分支持 | 以服务端权限为准，不代购；购买流程未实测 |
| 章节与全本缓存 | 支持 | 后台遇授权限制不弹扫码窗，须先开章授权后重试 |
| 离线阅读 | 支持 | 已缓存目录和正文可续读、关书重开 |
| 进度、笔记与统计同步 | 不支持 | 仅本地保存，没有已验证的远端读写协议 |
| 整书书评 | 部分支持 | 仅第一页，提示还有更多；没有后续页交互入口 |
| 章评与段评 | 不支持 | 阅读页评论仍绑定整本书；未找到可验证的章／段评接口 |
| 评论回复与写操作 | 不支持 | 未接入 |
| 账号切换与 Cookie 续期 | 部分支持 | 不同 Cookie 须先退出清理旧数据，未同步记录会丢失 |
