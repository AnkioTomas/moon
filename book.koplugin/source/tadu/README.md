## 登录与账号边界

在月读的塔读账号页选择微信扫码，或者选择“电脑浏览器登录”，按页面说明在官网登录后通过浏览器扩展授权。“粘贴 Cookie”是保留的手动入口；Cookie 来自电脑站请求头，不是 App 令牌。扩展回传只接收 `tadu.com` 域内 Cookie，保留有效父域 Cookie，不发送到微信扫码域。

每次扫码兑换使用独立匿名 Cookie 会话。只跟随 `https://www.tadu.com/` 的回调，校验 `/user/info` 通过才保存；取消、失败和迟到请求不能覆盖旧登录。扫码窗口有五分钟截止时间，关闭后停止当前请求并忽略迟到结果。

**稳定账号 ID 尚未完成真实账号核对，因此暂不允许直接用不同 Cookie 覆盖已有登录，包括同账号换 Cookie 的续期。** 必须先点“退出登录”，在已有确认框中明确同意清除该源的本地书架、阅读进度、笔记和缓存，再导入新登录。旧配置也遵守这条规则，不凭昵称判断账号，不静默清库。登录失效时仍保留退出入口；单纯网络失败不会清凭证。

退出会取消该源同步和缓存任务、清凭证，再通过现有本地清理机制删除记录，不向旧账号提交删除墓碑。尚未同步的本地记录会丢失，确认前应自行备份。

## 使用的公开协议

主域名为 `https://www.tadu.com`；图片使用官网提供的媒体地址。公共搜索、分类、详情、目录、书评不带账号 Cookie。书架与正文使用电脑站 Cookie；微信扫码域不带塔读 Cookie。App 阅读授权的创建、轮询、阅读页和正文共用本次操作的塔读会话。登录、账号校验、二维码和写请求的响应不缓存。

| 用途 | 方法与路径 | 关键字段、响应与登录要求 |
| --- | --- | --- |
| 官网登录 | GET `/v3/loginpage` | 微信、QQ、微博、密码、短信入口；交互和验证码由用户在官网完成。 |
| 官网密码、短信 | POST `/v3/login`、`/v3/sendCaptcha`、`/v3/webPhoneLogin` | 公开 JS 表明密码原值与 `username`、验证码 `ticket/randStr`，或 `phone/captcha` 提交。仅作为官网行为说明，插件不直接调用。 |
| 微信扫码 | GET `open.weixin.qq.com/connect/qrconnect`、`long.open.weixin.qq.com/connect/l/qrconnect` | `appid`、官方回调、`uuid/last/f=json`；404 已扫码、408 等待、405 确认、403 拒绝、402 过期。网络错误不伪装成过期。 |
| 会话兑换、校验 | GET `/webchat/invoke/?code=<code>&state=STATE`；POST `/user/info` | 兑换响应 Cookie 仅用于本次会话；校验响应须有 `data.user`。没有用户、坏响应和网络失败分开处理。 |
| 书架 | GET `/tadu/space/reader?pgNum=<page>` | HTML `data-bookid`；空架有 `bookrack_table_kong`。重定向首页或后续页失效是登录错误，不是空快照。 |
| 新增、删除 | GET `/api/v1/favorite/<bookId>`；POST `/tadu/api/v1/delFavorites` | 删除 body 为 `bookId`。保留已有协议：200 成功，新增 902 已收藏，901 未登录；不能仅据成功码清脏，须回读确认。删除路径与真实成功码仍需登录实测。 |
| 搜索 | POST `/search` | form `query`，HTML 书卡；响应错误不返回空数组。 |
| 分类分页 | GET `/store[/<node>]` | 九段官网节点：分类、状态、字数、排序、属性、条数、展示、页码、频道。直接采用页面的筛选链接与下一页链接，不维护分类 ID 表。 |
| 详情、目录 | GET `/book/<bookId>`；GET `/book/read/catalogue/<bookId>` | HTML 元信息、章节链接；稳定 ID 为书 ID，章节 UID 为链接里的章节 ID。 |
| 阅读权限 | GET `/book/<bookId>/<chapterUID>/` | 阅读页出现 `.appQrCode` 表示需要官方 App 扫码；`#bookPartResourceUrl` 提供该章真正的正文序号。仅检查 `canReadFlag` 或正文接口的 200 不足以证明完整权限。 |
| App 扫码阅读 | GET `/qrcode/invoke`；GET `/qrcode/check?qid=<qid>&token=<token>` | 创建返回 `status=200` 和 `data.qrcode`（PNG 的 data URI）、`qid/token`。0 和 1 继续等待，200 触发回读，其余状态过期；网络错误单独提示。二维码和票据只留在本次窗口内，五分钟截止，关闭停止轮询。 |
| 正文 | GET 阅读页声明的 `/getPartContentByCodeTable/<bookId>/<ordinal>` | `status=200`、`data.content` 也可能只是扫码前的预览，所以先核对阅读页权限。`data.url` 非空时，只允许从塔读同源下载字体，沿用本次阅读会话。只移除官网按章节 UID 的 Base64 标出的隐藏段，不删所有含“塔读”的段落。 |
| 书评 | GET `/v4/book/comment/<bookId>/1/1` | HTML `commentIntro`、作者、标题、正文、时间和页码；无需登录。官网详情页另有 POST `/book/comment/cover?bookId=<id>`，阅读页打开的也是整书评论。 |

## 本地与同步

用户操作先在本地 SQLite 和文件中生效，远端失败不回滚操作。删除先清本地缓存、写墓碑使书架立即消失，后续同步才调用远端删除。远端确认且回读不再有该书，才清除墓碑及依附记录；失败留待下一轮重试。账号请求捕获原 Cookie，登录改变后丢弃旧结果，不能注销新账号或确认新账号的书架。

正文成功后使用共享章节管线写文件并登记身份。目录缓存和旧章节路径不强制丢弃，正文出错不写成成功缓存。分页中间出错返回失败，不用已取到的第一页冒充完整书架或书城。

App 授权不替换书架账号 Cookie。候选 Cookie 归开章操作所有，仅在回读权限通过、正文解析及字体还原成功后保存为 `read_cookie`，并绑定当时的账号 Cookie；换登录不会复用旧阅读授权，退出也清除它。关闭或失败不覆盖旧会话。后台预取、全本缓存不弹扫码窗，遇到限制明确失败，须先打开章节授权后再重试缓存。授权回读仍受限、字体还原失败或服务端拒绝时，不缓存预览、不假报成功。

字体仅写临时文件供 KOReader 自带 FreeType 读取，完成、失败或取消均清理；不把字体或 `@font-face` 写入章节缓存，不修改阅读字体或嵌入字体开关。只还原 HTML 文本节点，保留标签、属性和图片。Unicode 正文经原章节管线落盘，章节路径、书名和身份不变，离线重开无需字体下载，复制、搜索、朗读及 AI 取得的也是还原后的文字。

`font_table.json` 是微软雅黑字形的 SHA-256 指纹与 Unicode 码点索引，不含字体文件或轮廓。每个轮廓的起点及轮廓排列顺序先规范化，保留控制点、坐标和字宽，不用相似度阈值猜字；不同字符仍有相同指纹时不入索引。可在装有该字体的 Windows 上运行 `tools/build_tadu_font.ps1 -OutputPath <输出文件>` 重新生成。生成器仅用于开发，插件不依赖 Windows 或额外安装的软件；官网以后更换字形时，需要核对并更新索引。

## 本轮实际验证

最初使用新建独立模拟器的沙箱账号、数据库、缓存和通信文件，没有复制真实用户数据，没有真实账号或远端写操作。后续用户在这个独立环境登录后，按用户反馈核对了已授权章节；两轮验证分开记录如下。

- 官网 DOM 与公开脚本：登录方式、强制腾讯验证码、分类与分页、目录、正文接口、书评粒度。
- 模拟器真实网络：书城 60 本、5 组筛选、每屏 8 本，共 8 屏；所有 60 本取得封面地址，书城末屏布局为两行筛选。
- 真实详情与目录：详情和封面地址可解析，测试书目录 483 章；第一章下载并由 KOReader 实际排版。
- 真实书评：第一页 30 条，页面链接显示共 7 页；不是拿空列表证明接口成功。
- 正式后台缓存队列：连续 3 章成功，失败 0；断网打开下一章、关书后断网重开均成功。随后还原网络方法，以不走缓存的实际请求确认恢复联网。
- 微信匿名二维码获取成功；**未完成手机扫码确认和会话兑换实测**。
- 离线用例覆盖同步回调取消、候选 Cookie 隔离、回调域限制、旧请求竞态、书架回读未确认、后续页失效、分类分页、正常段落保护和特殊字体拒绝。
- 三个频道各实测一批 20 本；塔读及共享分页的 6 个定向用例通过，共 143 条断言。正确加载仓库领域类型的 LuaLS 定向检查，塔读实现和测试均为 0 问题。全量回归仍有无关的翻译字典残留键失败，仓库级 LuaLS 也有其它模块的既有告警，未为本任务修改这些模块。

未实测：真实账号校验、浏览器扩展握手回传、验证码提交、密码与短信登录完成、稳定账号 ID、已购及未购章节、真实远端书架新增/删除。进度/笔记/统计同步、章评/段评、书评后续页和回复为未实现，而不是声称官网不支持。
