# 网易云阅读

| 能力 | 是否支持 | 备注 |
| --- | --- | --- |
| 手机号密码登录 | 支持 | 支持同一会话的图形验证码 |
| 微信扫码登录 | 支持 | 官方扫码确认后兑换网易会话 |
| 浏览器登录与 Cookie 导入 | 支持 | 电脑站登录后导入或粘贴 |
| 书架拉取 | 支持 | 读取官网书架 |
| 书架新增与移出 | 支持 | 本地先生效，远端确认后清脏／撕墓碑；失败重试 |
| 搜索与分类书城 | 支持 | 男频、女频、出版；动态分类、排序、资费及原创连载状态 |
| 详情与分卷目录 | 支持 | 保留章节顺序 |
| 免费与已购正文 | 支持 | 未购明确拒绝，不绕过权限 |
| 章节与全本缓存 | 支持 | 已缓存内容可断网续章和关书重开 |
| 阅读进度同步 | 支持 | 章节及章内比例；上传后回读确认 |
| 笔记与统计同步 | 不支持 | 仅本地保存 |
| 整书书评 | 支持 | 阅读器和章末评论入口均按整本书归属 |
| 章评与段评 | 不支持 | 当前电脑／移动 Web 未找到可验证接口，不代表 App 不支持 |
| 评论回复与写操作 | 不支持 | 未接入 |
| 账号切换 | 不支持直接隔离 | 须先关书、退出并清理旧本地数据；未同步记录会丢失 |
