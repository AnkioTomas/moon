# 网易云阅读

源 ID：`netease`。最近核对：2026-11-07。

## 当前可以做什么

- 手机号密码登录、微信扫码登录，以及电脑浏览器 Cookie 导入／粘贴。
- 拉取官网书架，读取详情、分卷目录、免费正文和账号已购买的章节。
- 搜索和浏览男频、女频、出版分类，按分类、热门／最新、资费及原创连载状态筛选；列表按页聚合至调用方 limit。
- 缓存章节或整本书；已缓存内容可断网续章、关书后离线重开。
- 登录后上传阅读进度，并读取官网的章节与章内位置。
- 在本机新增、删除书库成员，本地立即生效；联网后同步加入／移出官网书架，失败留待下次重试。
- 查看整本书评；电脑和移动阅读器的「评论」入口都是整书书评，不是按章或按段的评论。

## 当前不能做什么

| 项目 | 原因与实际行为 |
|---|---|
| 章节评论／段落评论 | 目前核对的电脑及移动 Web 阅读器都按整本书 ID 请求评论，未找到可验证的章评／段评接口；不能据此断言 App 不支持 |
| 直接换账号并自动隔离旧数据 | 当前只替换凭证，本地身份按 `source_id + stable_id`，没有账号维度；旧书架、缓存和待上传进度可能沿用 |
| 云端笔记／统计同步 | 本源没有实现对应上行／拉取接口；本地阅读记录不代表已上传网易 |
| 读取账号未购买的收费正文 | 站点权限限制，明确提示未购买，不绕过购买 |

换账号前应先关书，再从设置退出旧账号，然后登录新账号。现有退出确认会清除本机该源的书架、进度、笔记和缓存，**未上传的本地记录也会丢失**；清理不写删除墓碑，不会因此删除官网书架。这是现有退出路径，不是账号隔离保存。

## 使用的协议

使用官网 **Web 协议**，不是网易阅读 App 私有协议：

- 电脑站 `https://yuedu.163.com`：登录、账号校验、书架、详情、正文、书评和进度。
- 当前官网书架／详情页也运行在 `https://guofeng.yuedu.163.com`；书架读取和增删使用这个实际主机，读取禁用旧缓存，确保上行后取得新快照。
- 官方移动网页 `https://yuedu.3g.163.com`：公共搜索和分类 JSON，不携带电脑站 Cookie。
- 微信官方域：二维码与长轮询；确认后回网易兑换会话，不向微信发送网易 Cookie。
- 官网另有 DWR RPC 接口可返回账号 `userId`；**当前插件尚未接入账号标识和换账号判断**。

电脑会话需保留有效的主域／父域 Cookie。不能根据 Cookie 内容是否变化判定换账号：同账号重新登录或续期也可能产生不同 Cookie。

## 接口概览

### 当前实现已使用

路径相对电脑站，公共接口除外；参数中的 ID 和凭证都是运行时值。

| 用途 | 方法与路径 | 关键参数／语义 |
|---|---|---|
| 登录页 | `GET /loginForm.do` | `targetUrl` 指向账号页 |
| 手机号密码 | `POST /cellPhoneLogin.do` | `operation=login`、`cellPhone`、`password`、`remember_me`、`checkCode`；HTML `mobileCallback(...)` 表示结果 |
| 图形验证码 | `GET /captcha.do` | `d` 毫秒时间戳；与登录提交共用匿名会话 |
| 账号校验 | `GET /myinfor.do` | 有效会话返回账号页；匿名可能返回登录重定向，HTTP 层也可能报 `HTTP 302` |
| 书架 | `GET /shelf.do` | `operation=query_current`、`style=grid`、`page`；从卡片 `data-contentinfo` 解析书籍 |
| 详情／目录／进度 | `GET /getBook.do` | `id`；目录来自 portions，进度为 `curArticleUuid`、`curPagePercent` |
| 正文 | `GET /getChapterContent.do` 或 `/getArticleContent.do` | `sourceUuid`、`articleUuid`、`bigContentId`；`resultCode=0` 成功、`1` 未购买，content 按站点步骤解码 |
| 书评 | `GET /snsComment.do` | `operation=get`、`type=2`、`page`、`id` |
| 进度写入 | `POST /addUserReadLog.do` | `sourceUuid`、`articleUuid`、`curPagePercent`、`date`；章内百分比 0..100，成功返回数字 `1` |
| 公共搜索 | 移动网页 `GET /search/book/data.json` | `key` |
| 公共分类 | 移动网页 `GET /category` | 从官网链接动态获取分类 ID |
| 原创列表 | 移动网页 `GET /category/original/data.json` | `id`、`gender`、`sort`、`pay`、`state`、`page` |
| 出版列表 | 移动网页 `GET /category/publish/data.json` | 不传 state；热门／最新的 sort 编码与原创相反 |

进度接口的匿名请求也可能返回 `1`，所以写前先确认会话，写后通过详情回读核对；不能单凭成功数字清掉本地脏进度。

### 书架写接口与账号标识

增删已接入，来自当前官网脚本和书架页面，并经授权完成官网加入／移出及两次状态回读。账号标识接口尚未接入。

| 用途 | 方法与路径 | 关键参数／语义 |
|---|---|---|
| 加入官网书架 | `POST /subscribe.do` | 表单 `operation=addSub`、`id=<书籍ID>`；官网按 JSON `resultCode=0` 判成功、`-999` 判未登录 |
| 移出官网书架 | `POST /shelf.do?operation=unsub&source_uuids=<书籍ID列表>` | 多 ID 用逗号分隔；JSON `resultCode=0` 成功、`-999` 未登录 |
| 获取稳定账号标识 | `POST /dwr/call/plaincall/BaseBean.getUserInfo.dwr` | 官网 `getUserInfo(callback)` 调用 DWR `BaseBean.getUserInfo(false)`，回调对象有数值 `userId`；响应是 DWR JavaScript，不应当成普通 JSON 或直接执行 |

匿名、无效书 ID 的请求在 `guofeng.yuedu.163.com` 返回 JSON 错误：加入为 `-1`，移出为 `-999`。同路径在 `yuedu.163.com` 的该次匿名 POST 试探只返回 HTTP 200 空体。实现只认 JSON `resultCode=0`；空体、坏响应、非零码或网络错误均不清脏／撕墓碑。

稳定 `userId` 已通过官网只读调用确认，连续两次读取一致；未在两套真实账号之间进行切换对比，也未把任何真实账号标识写入本文件。

## 本地与同步行为

- 本地 sqlite 和文件是用户操作的真相；操作先落本地，远端失败不撤销本地操作。
- 复用公共 `source.shelf` 双向同步：先推删、再拉架、推本地独有成员，有新增成功再拉新快照；`dirty_only` 只推增删、不拉架。
- 删除入口先清本地缓存并标墓碑，不直接发网络请求；同步收到官网确认才撕墓碑。新增成功才标已同步，失败保留本地脏行，由推脏队列重试。
- 非空远端快照会将缺席的已同步旧书下架，保留本地脏行；空远端快照按公共防误删规则不清架。这不能替代换账号处理。
- 旧目录缓存离线仍可使用，联网后再升级所需协议字段。
- 上传进度失败保留脏状态；明确登录失效才标过期，暂时网络故障不登出。
- 本次按要求未处理账号边界。未退出旧号就直接登录新号，旧账号的墓碑、待新增成员或待上传进度仍可能写入新账号；遵循上文先关书、退出再登录的流程。

## 实测与已知限制

- 已实测密码和微信扫码、手动 Cookie 导入校验、书架拉取、免费及已购正文、章节／整本缓存、断网续读与重开、进度上传回读。
- 图形验证码拉图、显示和取消已实测；账号未触发真正的二次验证码提交，该提交分支只有自动测试覆盖。
- 浏览器扩展完整回传在独立测试端口未就绪，未完整实测；不能因此说 Cookie 导入不可用。
- 官网书架增删已实测：仅新增一本原本不在架上的免费测试书，读回在架；仅移除该测试书，再读回不在架。两次写入都返回 `resultCode=0`，没有操作原有书籍或触发旧脏数据同步。
- 已核对电脑阅读器评论模块、旧跟贴和移动阅读器；真实整书书评返回非空列表。章末按钮也只传整本书 ID，当前未找到可接入的章评／段评协议，不伪接。
- 账号切换的数据残留已用虚构账号的独立离线沙箱复现；尚未修复。
