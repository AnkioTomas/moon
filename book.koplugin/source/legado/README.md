# 开源阅读（Legado）书源

源 ID：`legado`，章节阅读模式。适配阅读 App 的 Web 服务、reader3 服务器版和轻阅读服务。

## 配置

在「设置 → 书库 → 账号 → 开源阅读 → 阅读服务地址」填写服务地址，也可扫描局域网。阅读 App 的 Web 服务通常形如 `http://设备地址:1122`；reader3 地址以 `/reader3` 结尾；轻阅读地址以 `/api/<版本号>` 结尾。reader3 和轻阅读可填写账号密码，普通阅读 App Web 服务不需要账号。

保存地址时会连接并读取一次书架，验证成功后才应用配置。地址、账号或密码变更后会重新建立连接会话。

## 功能

- 从服务端书架读取书籍；书籍需先在对应阅读 App／服务器添加。
- 读取章节目录和正文，章节在本机缓存；可预取和缓存整本书。
- 从服务端读取当前章节与位置，并在阅读后上报章节进度。
- 从服务端书架移除书籍。删除以服务端确认的书架快照为准。
- 使用服务端封面及章节正文中的图片地址（具体行为依后端实现）。

## 限制

- 不支持从月读把新书加入 Legado 书架；请在阅读 App 或服务端管理书籍。
- 进度精度为章节及章内偏移，不提供跨源笔记或统计同步。
- 阅读内容和目录需要服务端可访问；已缓存章节可离线继续阅读，未缓存内容无法离线下载。
- 轻阅读请求还依赖目录条目中的书源 `origin`；服务端书架中缺少对应书源信息时，目录或正文可能无法读取。

## 后端差异

后端按地址末段识别：`/reader3` 为 reader3，`/api/<数字>` 为轻阅读，其余按阅读 App Web 服务处理。不同后端的登录与请求编码不同，设置页会按对应协议连接；此适配不等同于导入阅读 App 的规则书源。

实现位于 `client.lua`、`mapper.lua` 和 `init.lua`；局域网发现位于 `scan.lua`。
