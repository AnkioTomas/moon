# 开源阅读（Legado）

| 能力 | 是否支持 | 备注 |
| --- | --- | --- |
| 服务连接 | 支持 | 阅读 App Web 服务、reader3、轻阅读；不是直接导入规则书源 |
| 局域网发现 | 支持 | 可扫描阅读服务地址 |
| 账号密码 | 部分支持 | reader3、轻阅读可配置；普通阅读 App Web 服务无需账号 |
| 书架拉取 | 支持 | 书籍须先在阅读 App 或服务端添加 |
| 加入远端书架 | 不支持 | 请在对应 App 或服务端添加 |
| 移出远端书架 | 支持 | 服务端确认后清除本地墓碑 |
| 目录与文字正文 | 支持 | 取决于服务端书源可用性；轻阅读需有效书源信息 |
| 封面与正文图片 | 部分支持 | 具体行为取决于后端 |
| 阅读进度同步 | 支持 | 章节及章内偏移；不同排版不保证精确对齐 |
| 笔记与统计同步 | 不支持 | 本地记录保留 |
| 书评、章评、段评与回复 | 不支持 | 桥接后端没有统一评论契约；不代表上游网站没有评论 |
| 章节预取与全本缓存 | 支持 | 内容需由服务端正常返回 |
| 离线阅读 | 支持 | 仅已缓存目录和章节 |
