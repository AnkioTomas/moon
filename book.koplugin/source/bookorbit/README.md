# BookOrbit

| 能力 | 是否支持 | 备注 |
| --- | --- | --- |
| 服务连接 | 支持 | 使用 BookOrbit 的 KOReader 同步账号；可导入官方插件配置 |
| 书库选择 | 支持 | 未选择时读取全部可访问书库 |
| 书架拉取 | 支持 | 分页读取 |
| 加入远端书架 | 不支持 | 本地新增书籍不上传 |
| 删除远端书籍 | 不支持 | 仅清本地缓存并留墓碑，不删除服务器藏书 |
| 详情与封面 | 支持 | 读取书籍元数据及可读文件 |
| 整本下载与阅读 | 支持 | EPUB、AZW3、AZW、MOBI、FB2、DOCX、PDF、DjVu、CBZ、TXT |
| 阅读进度同步 | 支持 | 仅已下载文件；按文件摘要匹配，使用 xpointer 或页码 |
| 划线同步 | 部分支持 | 仅上传已下载书籍的支持类型划线，不拉取远端笔记 |
| 阅读统计同步 | 不支持 | 本地记录保留 |
| 书评、章评、段评与回复 | 不支持 | 当前同步契约未接入；不代表所有服务端版本都没有评论 |
| 离线阅读 | 支持 | 已下载文件可用；连接、下载和同步需要服务器在线 |
