# BookOrbit 书源

源 ID：`bookorbit`，整本书模式。使用 BookOrbit 为 KOReader 提供的接口，不是通用 WebDAV 书源。

## 配置

在「设置 → 书库 → 账号 → BookOrbit」填写服务器地址、BookOrbit 的 KOReader 同步用户名与密码，并选择书库。也可在安装了 BookOrbit 官方插件时导入其账号配置。密码按 KOReader 同步协议生成 MD5 `userkey` 后保存。

服务器地址填写站点根地址；会自动去掉误复制的 `/api/v1` 或 `/api/v1/koreader` 后缀。账号必须在 BookOrbit 服务端启用 KOReader 同步。

## 功能

- 分页读取所选书库（未选任何书库表示读取全部可访问书库）。
- 查询书籍详情、封面及可读文件；按优先级选择 EPUB、AZW3、AZW、MOBI、FB2、DOCX、PDF、DjVu、CBZ 或 TXT 下载原文件。
- 对已下载文件使用 kosync 兼容接口同步进度；流式文档使用 xpointer，固定版式使用页码。
- 对已下载书籍上传支持的划线，并可从 BookOrbit 服务端删除这本书时由本地删除流程处理。

## 限制

- 书架只拉取，不支持把月读本地新增书籍推到 BookOrbit；BookOrbit 接口没有删除书籍能力，本地删除不会删除服务器上的藏书。
- 笔记目前只有上传路径，没有服务端笔记拉取；不应视为双向笔记同步。上传以已下载文件的摘要识别书籍，尚未下载的书无法同步进度或划线。
- 进度服务端以文件摘要识别文档；若两边文件内容不同，可能无法匹配到同一本书。
- 连接和下载需要服务器在线。下载文件会先写入临时文件，完成后再登记到本地书库。

接口实现位于 `client.lua`，书籍映射、下载、进度及划线适配位于 `init.lua`。
