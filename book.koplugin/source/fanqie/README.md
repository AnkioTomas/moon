# 番茄小说

| 能力 | 是否支持 | 备注 |
| --- | --- | --- |
| 扫码登录 | 已实现，未实测 | 番茄小说 App／抖音扫码；手机确认未实测 |
| 设备密码与手动 Cookie 登录 | 不支持 | 未提供入口 |
| 书架拉取 | 支持 | 包含分组 |
| 书架新增与移出 | 已实现，未实测 | 本地先生效，联网后上行；未验证真实增删及回读 |
| 搜索 | 部分支持 | 匿名 App 搜索，仅第一页 |
| 发现与榜单 | 部分支持 | 男／女频阅读榜、新书榜和动态分类，仅首屏 10 本 |
| 完整分类书城 | 不支持 | 未接完整书库、筛选和后续页 |
| 详情与目录 | 支持 | 官网详情、完整目录及缓存刷新 |
| 文字正文 | 支持 | App 协议下载和解密；受限内容未实测 |
| 漫画阅读 | 已实现，未实测 | 下载为 CBZ |
| 章节与全本缓存 | 支持 | 已缓存文字章节可离线重开；整本下载未实测 |
| 阅读进度同步 | 部分支持 | 仅章节位置，无精确章内位置；真实远端写入未实测 |
| 笔记与统计同步 | 不支持 | 仅本地保存 |
| 整书书评与章评 | 不支持 | 未接入可验证的独立接口，不代表 App 没有这些功能 |
| 段评 | 支持 | 按正文段落定位，支持分页和离线缓存 |
| 评论回复 | 支持 | 支持分页；回复页不单独缓存 |
| 评论表情 | 部分支持 | 已知标记使用非官方表情映射；图片来自 [Twemoji 16](https://github.com/jdecked/twemoji)，版权归 Twitter, Inc. 及贡献者，[CC-BY 4.0](https://creativecommons.org/licenses/by/4.0/)；离线缺图不保证字形可见 |
| 评论写操作 | 不支持 | 不发评、不点赞、不删评 |
| 账号切换 | 不支持直接隔离 | 没有稳定账号隔离；须先退出清理旧数据，未同步记录会丢失 |
