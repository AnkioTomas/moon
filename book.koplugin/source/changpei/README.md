# 长佩文学

## 能力与边界

电脑官网 Web 书源，稳定身份仍为小说 `novel_id`、章节 `id`。支持 App 扫描**官网二维码**登录、电脑浏览器 Cookie 粘贴及 moon-cookie-storage 扩展授权；扫码不是 App 私有 API。支持搜索、动态频道/分类、排序/价格/连载状态/字数筛选、原有榜单、详情、完整目录、免费及已购章节、章节缓存和本地进度。

账号密码在官方电脑网页输入后可以导入 Cookie；插件没有原生密码表单、短信登录或登录验证码窗口。用户已在独立模拟器完成扫码确认，修复后的登录保存与账号回读校验通过；电脑 Cookie 手动导入/扩展回传、已购内容及滑块提交尚未实测，不能把离线测试当成这些流程通过。

书架通过网页根目录接口拉取和新增/移出；分组内成员暂不枚举，不代表官网没有分组或增删接口。阅读历史只能表示读到哪一章，不能同步章内百分比。笔记、阅读统计只在本地保存，没有已核实的远端同步接口。

详情展示首页全书评论预览（官网列表也会汇总章评，保留对应章节名）；阅读设置打开「章节评论」后，在章末展示真正绑定该章节 ID 的讨论，支持后续页和离线缓存。两者不是段评；该 Web 协议未找到可验证的段落定位接口。列表中的回复数量可展示，但独立回复分页尚未接入；不提供发评、点赞或删评。官网评论接口有非空列表却 `count=0` 的响应，按实际页长判断是否还有下一页，总数此时仅是已读取数量下界。

## 协议概览

主域名 `www.gongzicp.com`，JSON API 前缀 `/webapi`，请求头 `Client: pc`。公开搜索、分类、详情和评论不携带账号 Cookie；目录、正文、书架和历史使用设备保存的登录态。扫码的 `moon_token`/`moon_refresh` 是本地存储载体，请求时移出 Cookie，token 放请求头。二维码和续期走官网 `cp.UserExternal` gRPC-web，不发送凭证到第三方域。

| 用途 | 方法与路径 | 关键参数、响应与错误 |
| --- | --- | --- |
| 搜索 | GET `/search/novels` | `k,page`；`data.list` |
| 频道/分类 | GET `/novel/typeGetList` | 省略 `id` 得频道，`id=<频道>` 得子分类 |
| 分类书库 | GET `/novel/novelGetList` | `tid,page,size=10,field,order=0,process,sell,number`；`list,count` |
| 榜单 | GET `/novel/rankingNav`、`/novel/rankingGetList` | `rid,date,page,tid=0` |
| 详情 | GET `/novel/novelInfo` | `id`；小说与作者、简介、分类 |
| 目录 | GET `/novel/chapterGetList` | `nid`；`volume/item/more`，`more` 是展开占位，不是漏拉的一页 |
| 正文 | GET `/novel/chapterGetInfo` | `cid,server=0`；AES-CBC 正文；未购与 `check>1` 滑块验证分开处理 |
| 书评/章评 | GET `/comment/getList` | `module=novel/chapter,cid,gift=0,page`；章评返回 `replay_module=novel_chapter`，校验归属 |
| 账号校验 | GET `/user/getUserInfo` | 要登录；稳定身份为 `data.info.show_uid`，已与官网 gRPC `/cp.UserExternal/info` 的 `uid` 比对一致；`9996` 表示未登录/失效 |
| 书架 | GET `/usercoll/getList` | 要登录；`did=0,filter=0,sort_key=1,sort_flag=2,page`，直到空页 |
| 书架增删 | POST `/usercoll/collHandle` | 要登录；`module=novel,cid,status=1/0`，服务器时间与官网签名 |
| 阅读历史 | GET `/usernovel/getHistory` | 要登录；日期分组的 `latest_read_cid` |
| 进度推送 | GET 正文后 GET 阅读历史 | 利用官网读章自动记历史；回读确认为当前章才报告成功 |
| 扫码/续期 | POST `/cp.UserExternal/get_qrcode_token`、`qrcode_polling`、`get_token` | 官网 protobuf 帧，`version/imei`；待扫码长轮询约 30 秒，超时不能按普通请求设置；等待、确认、拒绝、过期、取消；不缓存敏感响应 |
| 滑块 | POST `/novel/readCheck` | 要登录；官网凭据，内层 `data.code=200` 才成功 |

分类每次按调用方 limit 聚合多页（默认 60），不把官网单页 10 本当 UI 上限；分页失败明确报错，不返回部分结果冒充完整书库。`cate:` 节点记录筛选；已有 `榜单号:子榜值` 节点继续可用。换频道清除不兼容子分类，保留排序/价格/状态等通用条件。

## 本地、同步与账号边界

本地 sqlite 和文件是唯一真相。本地增书先标脏，删除先清缓存、写墓碑，书架立即消失；远端增删由现有 `source.shelf`/推脏队列执行，远端失败留脏行或墓碑等待重试。删除入口不直接联网。没有账号时不运行远端同步。本轮未授权实际远端增删，不能据此声称双向同步实测通过。

进度先本地落盘，联网后按章收敛，回读不符则保留待同步状态。取章会改变官网阅读历史，预取/全本缓存也可能把它推到后续章节，关书推当前章收敛；这是已知官网行为，章内位置只存本地。临时未购提示不是正文缓存；内容错误不记缓存成功。已有目录版本不匹配时，离线仍使用旧目录，不强迫丢弃可读缓存。

每次登录先验证账号，再比较稳定 `uid`，不是按 Cookie 或昵称判断换号。同账号续期保留数据；不同账号必须在界面确认清除本设备长佩书架/进度/笔记/缓存（含未同步记录），不会操作远端书架。确认后结束旧阅读会话、取消旧任务，停用旧凭证再清本地。旧配置没有账号 ID 时先校验旧 Cookie；无法确认则拒绝覆盖，需用户显式退出后重登。失败、取消、迟到旧登录/续期请求不得覆盖新凭证；网络故障不当成登出。

## 本轮验证（2026-11-07～2026-11-08）

已从官网 DOM、公开脚本及匿名接口核对分类/筛选、详情、目录和评论。公开测试书 `2125021` 的目录有 104 个 item、2 个 volume、1 个展开占位；章节 `8267486` 的章评首页 10 条、次页 8 条、远末页为空，实际归属章节而非全书。

本任务独立联网模拟器实际跑通搜索、分类筛选、详情、104 章目录、书评预览和章评首页/次页；书城聚合 60 本，每屏 8 本、共 8 页，第二页 8 本、末页 4 本。截图核对两行筛选及当前频道选中。临时断网后，目录和章评缓存仍可读取；恢复后用禁用缓存的真实请求确认联网。匿名正文明确返回登录错误，不伪报缓存成功。

实际获取并显示官网二维码，核对待扫码长轮询约 30 秒返回等待状态，取消后关闭窗口；已修复原先 15 秒请求超时导致二维码被过早关闭的问题。2026-11-08 用户扫码确认后发现「长佩账号标识缺失」：旧 JSON 接口返回的是 `data.info.show_uid`，不是 `data.uid`。与官网 gRPC 身份接口比对一致后修正映射，仅向登录边界传递归一化 `uid`；复用用户已确认的会话完成登录保存，随后重新请求账号接口验证通过，未输出账号资料或凭证。

相关离线回归曾为 12 个文件、447 个断言通过，覆盖分类多页/筛选保留、同步及异步请求取消、坏响应、评论归属/末页、登录换号/取消/旧配置、续期竞态、迟到旧账号写请求和进度回读。账号字段修正后再跑账号校验、换号与扫码的 3 个文件，70 个断言通过，包含实际嵌套字段、无效标识、网络失败和不传播个人资料。最终长佩 LuaLS 定向诊断（完整依赖、绝对路径）为 0 问题；全库另有无关告警。全量回归另有其他书源文案缺译导致的失败，不属于长佩新增文案。验证码提交、已购正文、章节缓存后的离线重开、书架增删/进度远端写入未获授权，尚未实测，不执行购买或远端账号写操作。
