# 长佩文学

| 能力 | 是否支持 | 备注 |
| --- | --- | --- |
| App 扫码登录 | 支持 | 扫描官网二维码，确认后校验账号再保存 |
| 浏览器登录与 Cookie 导入 | 已实现，未实测 | 支持手动粘贴和浏览器扩展回传 |
| 设备密码、短信与登录验证码 | 不支持 | 其他登录方式在官网完成后导入 Cookie |
| 书架拉取 | 部分支持 | 读取根目录，不枚举分组内成员 |
| 书架新增与移出 | 已实现，未实测 | 本地先生效，后续同步；远端失败保留脏行或墓碑 |
| 搜索与分类书城 | 支持 | 动态频道、分类及排序、资费、状态、字数筛选，默认聚合 60 本 |
| 榜单 | 支持 | 保留原有榜单入口 |
| 详情与完整目录 | 支持 | 保留小说和章节身份 |
| 免费与已购正文 | 部分支持 | 需有效登录及阅读权限；已购正文未完成实测 |
| 阅读安全验证 | 部分支持 | 已接官网滑块流程；实际提交未验证，不绕过验证 |
| 章节与全本缓存 | 支持 | 权限不足的提示不计入正文缓存；缓存流程未完成真实登录实测 |
| 离线阅读 | 支持 | 已缓存章节、目录和章评可用 |
| 阅读进度同步 | 部分支持 | 仅章节位置；读章及预取可能改变官网历史，关书再收敛 |
| 笔记与统计同步 | 不支持 | 仅本地保存 |
| 整书评论 | 部分支持 | 首页预览可能汇总章评，保留对应章节名 |
| 章评 | 支持 | 真正按章绑定，章末入口、分页和离线缓存 |
| 段评 | 不支持 | 当前 Web 协议未找到可验证的段落定位接口 |
| 评论回复与写操作 | 不支持 | 可展示回复数，未接回复分页、发评、点赞或删评 |
| 账号切换 | 部分支持 | 同账号可续期；换号须确认清理旧本地数据，未同步记录会丢失 |
