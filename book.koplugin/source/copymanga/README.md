# 拷贝漫画

| 能力 | 是否支持 | 备注 |
| --- | --- | --- |
| API 站点选择 | 支持 | 建议使用已核对的 `https://api.manga2026.xyz`；保留旧站点及自定义地址，不自动切换 |
| 账号密码登录 | 支持 | 原 API 登录，保存前校验账号；新登录不保存密码 |
| Cookie、扫码与验证码登录 | 不支持 | 未接入可验证的 API 契约 |
| 搜索与书城 | 支持 | 搜索、男／女频日周月总榜及题材，默认聚合约 60 本 |
| 详情与分组目录 | 支持 | 分组分页、默认组在前，保留章节 UUID |
| 漫画阅读 | 支持 | 按页图顺序下载 CBZ；使用 App API，不解析官网 HTML |
| 受限与付费漫画 | 未验证 | 没有真实账号权限验证，不承诺受限章节可读 |
| 章节缓存与离线阅读 | 支持 | 复用已缓存 CBZ；未缓存内容离线明确失败 |
| 书架拉取 | 支持 | 分页读取收藏 |
| 书架新增与移出 | 已实现，未实测 | 本地先生效，收藏上行后回读确认 |
| 阅读进度同步 | 部分支持 | 旧 API 保留章节级读写；当前推荐节点未验证写入和回读，只保存本地进度 |
| 笔记与统计同步 | 不支持 | 仅本地保存 |
| 书评、章评、段评与回复 | 不支持 | 未接入可验证接口，不代表其他客户端没有评论 |
| 账号切换 | 部分支持 | 需先退出清理旧数据，未同步记录会丢失；换站点不改变书籍身份和 CBZ 路径 |
