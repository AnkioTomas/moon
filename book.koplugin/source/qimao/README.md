# 七猫小说

| 能力 | 是否支持 | 备注 |
| --- | --- | --- |
| 手机短信登录 | 已实现，未实测 | 发码前由远程网页完成数美滑块 |
| Token 导入 | 已实现，未实测 | 浏览器登录态导入或手动粘贴，保存前校验 |
| 密码与扫码登录 | 不支持 | 未提供设备入口 |
| 书架拉取 | 支持 | 登录后分页读取；真实账号流程未实测 |
| 书架新增与移出 | 已实现，未实测 | 本地先生效，联网后推送；远端删除没有读回确认 |
| 搜索 | 部分支持 | 仅第一页 |
| 分类书城 | 支持 | 动态频道、分类、子分类、排序、字数、更新时间和完结状态，支持续页 |
| 目录与正文 | 已实现，未实测 | 目录排序和章节缓存；App 风格正文解密未完成实测 |
| 已购与未购权限 | 未验证 | 不承诺付费章节可读，不绕过购买 |
| 章节缓存与离线阅读 | 支持 | 仅已成功缓存的目录和章节；设备阅读流程未实测 |
| 阅读进度同步 | 部分支持 | 仅章节位置，无章内位置；远端写入与回读未实测 |
| 笔记与统计同步 | 不支持 | 仅本地保存 |
| 书评、章评、段评与回复 | 不支持 | 当前 Web 协议未找到可验证接口，不代表 App 没有评论 |
| 账号切换 | 不支持隔离 | 缺少稳定账号绑定，换 Token 后旧待同步数据有串号风险 |
