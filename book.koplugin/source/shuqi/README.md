# 书旗小说

| 能力 | 是否支持 | 备注 |
| --- | --- | --- |
| 手机短信登录 | 已实现，未实测 | 通过远程网页完成官方安全验证，保存前校验账号 |
| 浏览器登录与 Cookie 导入 | 支持 | 手动粘贴或扩展回传，只保存必要会话字段 |
| 设备密码与扫码登录 | 不支持 | 未提供入口 |
| 书架拉取 | 支持 | 读取书签书架，账号请求串行执行 |
| 书架新增与移出 | 已实现，未实测 | 本地先生效，另一次请求回读确认；失败保留脏行或墓碑 |
| 搜索 | 部分支持 | 首批约 20 本，没有搜索翻页 |
| 分类书城 | 支持 | 动态频道、分类、状态、字数、更新时间及后续页，默认聚合 60 本 |
| 详情与目录 | 支持 | 保留书籍、章节 ID 和缓存路径 |
| 免费正文 | 支持 | 未购或缺正文地址时提示购买，不缓存提示页 |
| 已购正文 | 已实现，未实测 | 需目录提供有效的已购正文地址 |
| 章节与全本缓存 | 支持 | 支持预取、范围和后台缓存，下载失败记为失败 |
| 离线阅读 | 支持 | 已缓存正文可续章、关书重开 |
| 阅读进度同步 | 部分支持 | 章节位置及全书比例，回读确认；无精确章内坐标 |
| 笔记与统计同步 | 不支持 | 仅本地保存 |
| 整书书评 | 部分支持 | 详情仅第一页；客户端可续页，界面未接后续页 |
| 章评与段评 | 不支持 | 当前 Web 协议未找到可验证接口 |
| 评论回复与写操作 | 不支持 | 未接入 |
| 账号切换 | 部分支持 | 同账号可续期；换号须先退出清理旧数据，未同步记录会丢失 |
