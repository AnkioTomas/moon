# 书旗小说源

最近核对：2026-11-07。使用书旗电脑站与官方移动网页协议，不使用 App 私有接口。

## 支持范围

| 功能 | 当前实现与边界 |
| --- | --- |
| 登录 | 手机短信验证码（通过月读远程管理网页完成安全验证）、电脑浏览器扩展回传 Cookie、手动粘贴 Cookie。Cookie 必须通过官网账号接口校验后才保存。密码与扫码没有独立插件入口，不能据此推断官网不支持。 |
| 搜索 | 匿名可用；当前接口返回一批 20 本，不提供搜索结果翻页。 |
| 书城 | 电脑站真实书库；动态读取频道、分类、连载状态、字数和更新时间。按官网分页聚合，默认最多 60 本；兼容旧版保存的分类名称。频道切换使用官网链接，重置其余筛选。 |
| 书架 | 登录后拉取书签书架；实现加架、移架上行，写入后另一次请求回读确认。不把写请求中的列表当成已确认结果。 |
| 目录与正文 | 稳定书籍 ID、章节 ID 和原缓存路径不变；支持免费章节，以及目录提供已购正文地址的章节。没有可用地址的未购章节显示购买提示，提示页不计入正文缓存。 |
| 缓存与离线 | 支持预取、指定范围和全本缓存；复用现有后台任务队列。已落盘目录和正文可以离线阅读、续章及重开；未缓存内容仍需要网络。未购或下载失败的章节记为缓存失败。 |
| 书评 | 匿名整书书评，校验每条评论所属书籍。客户端支持服务端分页；当前详情页只展示第一页并提示还有更多，尚无界面翻页。首页可能包含额外置顶项，不一定恰好 20 条。 |
| 章评、段评与回复 | 本次检查了阅读页、公开脚本和实际请求；该 Web 协议未找到可验证的章评、段评接口，不把整书书评复制到每章。回复分页尚未实现。 |
| 进度 | 登录后同步章节位置与全书比例；写入后回读确认章节 ID 和比例。不支持精确章内坐标。 |
| 笔记与统计 | 月读本地保存；本源没有远端笔记、统计同步实现。 |

## 协议概览

公共书库、搜索、评论及免费正文请求不携带账号 Cookie。登录和书签同步使用官方移动网页返回的会话字段；敏感响应不走公共缓存。

| 用途 | 方法与接口 | 关键结构及语义 | 登录 |
| --- | --- | --- | --- |
| 分类书库 | `GET https://www.shuqi.com/store` | `sz/fc/st/wd/tm/page`；分类与选项从 HTML 链接读取，`fc` 可含多个分类。当前每页 24 本。 | 否 |
| 搜索 | `GET https://read.xiaoshuo1-sm.com/novel/i.php` | `do=is_search`、关键词、时间戳及网页签名；搜索响应的成功状态为 `1`。 | 否 |
| 详情 | `POST https://content.shuqireader.com/openapi/book/info` | `bookId/user_id/timestamp/sign/platform`；公共请求使用匿名身份。 | 免费详情不需要 |
| 目录 | `GET https://content.shuqireader.com/openapi/book/chapterlist` | 同一网页正文签名；签名完成后附加 `tk/imei/sn`，这些字段不参与该签名。目录区分免费、已购与未购正文地址。 | 免费目录不需要；购买状态需要会话 |
| 正文 | `GET` 目录给出的正文地址 | 沿用官网 ROT13、Base64 和 HTML 解码流程；没有正文地址时明确报告未购，不尝试绕过购买。 | 由章节权限决定 |
| 整书评论 | `GET https://comment.alwx.alibaba.com/novel/i.php` | `do=sp_get/bookId/fetch=merge/source=store/size=20/page/score=yes`；`status="200"`，`data` 为列表，`info.total` 是条数、`info.count` 是总页数。 | 否 |
| 发短信 | `POST https://ocean.shuqireader.com/api/jaccount/sso/captcha/sendCode` | 手机号、滑块结果、时间戳和网页网关签名；未注册手机号可能自动注册，界面要求先同意协议。 | 否 |
| 验证码登录 | `POST https://ocean.shuqireader.com/api/jaccount/sso/vcode/login` | 验证码与本次验证实例的设备指纹；成功响应必须提供稳定账号 ID，验证通过后才保存会话。 | 否 |
| Cookie 校验 | `GET https://ocean.shuqireader.com/webapi/jaccount/accountapi/v1/sapi/account/userBaseInfo` | `userId/sqSv/sign/key/_public`，会话令牌仅放 `Authorization: Bearer <token>`，不放 URL。成功响应中的账号 ID 必须与导入账号一致。 | 是 |
| 书架、进度 | `POST https://jbookmark.shuqireader.com/api/v1/sync/bookmarks` | 会话字段和 JSON `data`；`userid` 为数字，`bookmark` 为数组，`get_data="1"`。动作 `1/3/2` 分别用于加架、移架、进度；`add_time` 为毫秒，`last_update` 为秒字符串。写入比例是万分比，回读兼容小数比例，确认时按服务器三位小数精度比较并严格核对章节。 | 是 |

坏 JSON、字段缺失、评论归属错误和网络失败不会伪装为空列表成功。书架、进度写入若无法回读确认，返回「同步结果未确认，请重试」，不清除待同步状态。

书签接口会拒绝同账号的并发请求：HTTP 200 仍可能返回业务状态 `10006`、提示「未知状态码错误」。该接口的全部读写在登录会话内串行执行，不影响其他 HTTP 接口；取消只取消自己的请求，排队取消或账号改变后不会再发出旧请求。请求失败仍返回原错误并附业务状态码，释放队列让后续请求继续，不伪造成功或清除本地脏标记。

## 登录操作

在书旗账号设置中可选择短信登录、电脑浏览器登录或粘贴 Cookie。官方登录入口是 `https://t2.shuqi.com/oauth/login?priority=code&redirect_uri=https%3A%2F%2Ft.shuqi.com%2Fmyself`，账号校验页为 `https://t.shuqi.com/myself`。

电脑浏览器登录使用月读 Cookie 扩展：在官网完成登录后，按月读远程管理页面的提示回传 Cookie。手动登录则在官网登录后，将 Cookie 粘贴到模拟器／设备的「粘贴 Cookie」输入框，不要发到聊天、截图或日志里。扩展回传仅接受 `.shuqi.com` 父域及 `t.shuqi.com` 的 Cookie。

Cookie 需包含 `shuqi_user_id` 和 `shuqi_token`，可带 `shuqi_fingerprint`。插件只保存校验后的必要会话字段，不保存整份 Cookie，也不会把无关 Cookie 发给正文、搜索或评论接口。无效 Cookie、网络失败、取消或账号不匹配都不会覆盖原会话。

短信安全验证页面使用官网 Fingerprint2、AWSC UM／UAB 和阿里云滑块 SDK；每个验证实例独立生成指纹，不读取月读远程管理域的 Cookie。发短信和验证码登录沿用该浏览器的 User-Agent；SDK 初始化失败直接提示，不带空的初始化结果继续发送。登录遇到安全验证 HTML 或没有错误文案的状态码时，会明确提示官网 Cookie 登录或显示状态码，而不是只显示「登录失败」。

Fingerprint2 使用官网 CDN `https://render-resource.11222.cn/third/fingerprint2/fingerprint2.min.js`，AWSC 与阿里云滑块也加载官方资源，不随插件打包这些 SDK。验证页加载失败或超时会显示具体脚本地址，并提醒「可能被广告拦截插件阻止」，同时提示检查插件设置或网络，或改用 Cookie 登录。浏览器无法可靠区分广告拦截与网络故障，所以不将广告插件断言为唯一原因。

重试复用已加载的 SDK，移除失败／超时的脚本节点，不重复加载全部 SDK。指纹只用于用户发起的短信登录，不读取远程管理域 Cookie，也不伪造指纹；插件不自动修改浏览器扩展或拦截规则。

## 本地与账号边界

书架加入、进度及笔记先落本地并立即生效；已登录且联网时，由现有推脏行机制收敛到远端。删除沿用源基类：先清缓存并留下本地墓碑，远端确认后才移除书库记录；失败保留待重试状态。未配置账号时没有远端可同步，纯本地删除按基类规则完成。

同账号续期可以替换会话；不同账号必须先显式退出，登录请求本身不会自动清库或把旧数据推给新账号。退出确认会清理本机该源的书架、进度、笔记与缓存，未同步记录也会丢失，请先完成同步。旧配置缺少稳定账号 ID 时，也需要退出后重新登录。

每次滑块验证独立持有设备指纹。关闭或取消登录后，迟到响应不能覆盖旧登录；账号状态改变后，旧请求不能保存新的书架响应。
