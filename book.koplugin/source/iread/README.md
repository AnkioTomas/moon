# iRead（爱阅读）

| 能力 | 是否支持 | 备注 |
| --- | --- | --- |
| 个人 Token 登录 | 支持 | 保存前校验；与 Cookie 互斥 |
| 浏览器登录与 Cookie 导入 | 支持 | 手动粘贴或扩展回传；完整扩展握手未实测 |
| 设备密码与扫码登录 | 不支持 | 在 iRead 官网完成账号登录 |
| 搜索与发现 | 支持 | 游客公共书源、账号配置书源及动态发现入口 |
| 发现分页 | 部分支持 | 仅支持已核实的页面占位符；无占位符只取一批，不执行规则 JavaScript |
| 书架拉取 | 支持 | 读取个人书架 |
| 书架新增与移出 | 已实现，未实测 | 收藏开关写前查架、写后回读，失败保留待同步状态 |
| 目录与文字正文 | 支持 | 取决于服务端规则可用性；上游失效或空正文明确失败 |
| 漫画与图片正文 | 不支持 | 未实现图片落地，不把空正文作为成功缓存 |
| 付费内容 | 未验证 | 取决于上游规则、登录和购买权限，不保证所有付费书源可读 |
| 章节与全本缓存 | 支持 | 已缓存章节可离线阅读 |
| 阅读进度同步 | 部分支持 | 仅章节位置；同章保留远端原位置，不伪造跨排版精确坐标 |
| 笔记与统计同步 | 不支持 | 仅本地保存 |
| 书评、章评、段评与回复 | 不支持 | 当前 Web 契约未找到可验证接口，不代表上游网站没有评论 |
| 账号切换与凭据续期 | 部分支持 | 新凭据须先退出旧登录并清理本地数据，未同步记录会丢失 |
