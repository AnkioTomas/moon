# 豆瓣阅读

| 能力 | 是否支持 | 备注 |
| --- | --- | --- |
| App 扫码与短信登录 | 支持 | 豆瓣阅读 App 扫码；短信支持国际区号，历史授权迁移交由官网确认 |
| 浏览器登录与 Cookie 导入 | 支持 | 手动粘贴或浏览器扩展回传 |
| 设备密码登录 | 不支持 | 未接入 |
| 搜索与分类书城 | 支持 | 原创、出版动态分类、子分类及排序、资费和状态筛选 |
| 书架拉取与分组 | 支持 | 官网分组可作为书库分类 |
| 加入远端书架 | 支持 | 本地先生效，上传后回读确认 |
| 移出远端书架 | 已实现，未实测 | 清缓存、留墓碑；远端确认后清记录 |
| 目录与正文 | 支持 | 专栏按章；出版电子书按正文目录切章，免费内容可匿名读取 |
| 已购正文 | 已实现，未实测 | 以官方阅读权限为准，不绕过购买 |
| 章节与全本缓存 | 支持 | 兼容旧缓存，已缓存章节可离线续读和重开 |
| 阅读进度同步 | 部分支持 | 专栏下行不能恢复最近章，上行持久化未确认；出版仅近似章首比例 |
| 阅读时长同步 | 部分支持 | 上传本地会话，拉取累计及近 30 日时长；不把访问记录伪造为阅读会话 |
| 个人笔记同步 | 不支持 | 未接个人划线、书签和笔记双向同步 |
| 整书书评 | 部分支持 | 长短评首批预览；首页匿名，后续页需登录 |
| 章评 | 部分支持 | 仅专栏章节；章末入口、分页和缓存，后续页需登录且未完成真实登录实测 |
| 段评 | 支持 | 保留按段落 ID 定位的他人批注，与章评共存 |
| 评论回复与写操作 | 不支持 | 未接回复分页、发评、点赞或删评 |
| 账号切换 | 部分支持 | 同账号可续期；换号须先退出清理旧数据，未同步记录会丢失 |
