# 豆瓣阅读书源

使用豆瓣阅读电脑 Web 协议（`read.douban.com`），不是豆瓣读书的图书信息 API。登录授权由官方 `accounts.arkread.com` 完成；没有接入 App 私有接口。

## 支持范围

| 功能 | 当前实现与边界 |
| --- | --- |
| 登录 | 豆瓣阅读 App 扫码、手机号验证码；电脑浏览器登录后手动粘贴 Cookie，或由月读浏览器扩展回传。短信登录使用独立候选会话，支持国际区号、服务端重发倒计时及关闭取消；不保存手机号和验证码。遇历史数据迁移授权，提示先在官网完成，不代替用户确认。插件不收集密码，不实现未经核对的密码接口。 |
| 搜索与书城 | 匿名搜索；原创、出版分类来自官网动态分类树，包括子分类。支持热门、最新、销量、好评；出版另有价格排序、豆瓣评分及付费筛选；原创支持免费、连载与完结筛选。源站每页 20 本，按调用方 limit 聚合，默认最多取到 60 本后交给桌面分页。 |
| 书架 | 拉取作品 ID 后补作品资料；本地增删走公共书架同步。默认将官网分组作为书库分类，多组成员按官网分组顺序取第一个，未分组清除旧分类；关闭后使用题材，基础资料无题材时使用原创／出版频道。已授权新增并回读确认，远端删除尚未授权实测。 |
| 目录与正文 | 专栏按章节阅读；电子书按正文目录段落切章。兼容段落文字字符串与 `plaintext` 片段数组，片段按原顺序连接。免费内容可匿名读；付费只请求官方允许读取的内容，不绕过购买。未购提示页不写成有效章节缓存。 |
| 缓存与离线 | 使用公共章节缓存和全本缓存任务。已有有效缓存可离线打开；协议版本变化时，离线保留旧目录，不强制联网迁移。未缓存正文仍需要网络。 |
| 进度 | 按本地章节选取真实正文段落及官网分段索引，以表单上传；专栏只写章节 article，不伪造整部作品进度。电子书章首百分比按 `(idx - 1) / total` 估算。当前下行仍查询整部作品，不能恢复专栏最近章；专栏写入返回 `r=0` 后实际回读仍为空，尚未确认持久化，不能声称完整双向同步或段内精确续读。 |
| 时长 | 新增拉取官方累计时长和近 30 天按日时长。使用官网 `duration`（秒，包含读书和听书），不是分钟或毫秒；7 日汇总不再额外相加，避免与日桶重复。保留本地阅读会话上传。 |
| 阅读记录 | 官网 `/reading_history/` 返回作品与 `historyAccessTime`（最近访问时间），不提供每次阅读的起止时间或时长。本次未将其伪造为月读的阅读会话；本地采集的真实阅读记录照常保留。也未从账户日桶臆造单书时长。 |
| 评论 | 按段落 ID 查询他人批注并映射到本章段落，只有非空 `note` 算段评；已实测非空标记及评论列表。账号设置页的「显示段评」开关立即刷新显示。没有接入独立书评、章评、回复或发评接口；本次 Web 研究未找到这些功能的可验证接入接口，不代表其他协议不支持。 |
| 笔记 | 未实现自己的划线、书签和笔记双向同步；他人段评不是个人笔记同步。 |

## 协议概览

| 用途 | 方法、路径 | 关键参数与响应 | 登录 |
| --- | --- | --- | --- |
| 分类树 | `GET /category/` | 页面公开 `Ark.kindTree`；区分原创、出版并保留子分类 | 否 |
| 分类书单 | `POST /j/kind/` | `kind`、`sort`、`page`；价格为 `minPrice/maxPrice`，状态为 `isFinished`；返回 `list/total` | 否 |
| 搜索 | `POST /j/search_v2` | `q`、`page` 与持久化 GraphQL 查询哈希；返回 `list` | 否 |
| 作品、阅读入口 | `POST /j/graphql` | `worksId` 与公开脚本中的持久化查询；返回 `readerUrl` 等 | 免费入口可匿名；已购权限需登录 |
| 专栏目录 | `GET /j/column/<column_id>/` | `chapters`；免费、已购与可读标记 | 免费目录可匿名 |
| 正文 | `POST /j/article_v2/get_reader_data` | 表单 `aid`；`r=0` 时解密官方正文载荷，拒绝错误与空正文 | 免费内容可匿名；已购需登录 |
| 他人批注 | `POST /j/article_v2/<aid>/annotations_by_paragraphs` | 表单 `paragraph_ids`；数组中的 `startContainerId/note` 用于段落归属 | 按官方权限 |
| 书架 | `GET/POST/DELETE /j/bookshelf/` | 拉取 `worksIds`；增删提交 `worksIds` 数组 | 是 |
| 书架分组 | `GET /j/bookshelf/folder/` + `POST /j/graphql` | 先取有序 `folderIds`；查询 `user.bookshelf.folders.list` 的 `id/name/libraryList.list[].worksId`，严格检查完整结果 | 是 |
| 进度 | `GET/POST /j/progress/` | GET 查询 `works_id`；POST 表单 `works_id/paragraph_id/paragraph_offset/part_sequence/part_paragraph_sequence`，电子书另有 `percentage`；明确非零 `r` 或坏响应算失败，不只判断 HTTP 200 | 是 |
| 本地会话上传 | `POST /j/reading_time` | JSON 数组 `worksId/beginTime/endTime`；时间为 ISO 字符串 | 是 |
| 官方时长拉取 | `POST /j/graphql` | 查询哈希 `sha256:03a310ea89efc4801c0071c4d3c5bcae7ae9227cada95c731e7222a0811e491f`；`userId/beginDate`；`user.readingTimeTotal/readingTimeHistory` | 是 |
| 官网最近阅读列表 | `GET /j/shelf/history` + `POST /j/graphql` | 先取 `worksIds`，再查询 `worksList[].historyAccessTime`；本次仅研究，未当作会话导入 | 是 |
| 登录授权 | `GET /oidc/login` | 仅跟随已确认的阅读站和授权站 HTTPS 跳转 | 匿名独立会话 |
| App 扫码 | 授权站 `POST /oidc/qrcode/generate`、`POST /oidc/qrcode/status` | `url/expires_in`、`code/confirmed`；确认后重新进入授权页兑换阅读站会话 | 匿名独立会话 |
| 短信验证码 | 授权站 `POST /oidc/phone/verify_code`、`POST /oidc/phone/verify` | JSON `phone_number`（含国际区号）、`code`；发送返回 `retry_after`，验证后通过官方授权跳转兑换阅读站会话 | 匿名独立会话 |

搜索与分类请求不发送账号 Cookie。登录、扫码和正文响应不使用 HTTP 持久缓存；账号 Cookie 只发送至相应官方主机，浏览器回传只保留阅读站及适用父域 Cookie。
授权站 POST 同时携带该候选会话的 CSRF 与同源 Referer；缺少 Referer 时官方二维码生成实际返回 HTTP 400、`code=1002`，不能当作二维码图片加载问题。

## 本地与同步

本地文件和 sqlite 是唯一真相。书架操作先在本地生效并标脏；删除先清缓存、留墓碑，后续公共同步确认远端删除后才清记录。离线及远端失败保留脏状态，不回滚成用户操作失败。

统计同步复用月读的「先推本地、后拉云端」流程。官方日桶和累计快照各自覆盖自己的范围，不删除已上传的本地逐页历史，不碰近 30 天以外的旧日桶。未上传或快照之后的新本地时长继续计入；云端汇总只有时长，没有页数，不凭空补页数。坏响应或网络失败不会替换已有统计。

登录校验成功后才替换持久会话；失败、取消、迟到请求保留旧账号。只有稳定用户 ID 相同才能续期；换号须先通过已有退出确认清理旧源数据，避免旧书架、墓碑、进度和时长推给新账号。旧配置缺少用户 ID 时也要求明确退出，不能静默清库。
