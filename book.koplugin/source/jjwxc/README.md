# 晋江文学城

| 能力 | 是否支持 | 备注 |
| --- | --- | --- |
| App 账号密码登录 | 已实现，未实测 | 支持手机／邮箱设备验证；密码不保存，不靠密码自动重登 |
| 浏览器登录与 Cookie 导入 | 已实现，未实测 | 手机 Web Cookie，支持手动粘贴及扩展回传 |
| 扫码登录 | 不支持 | 未接入 |
| 书架拉取 | 支持 | Web 收藏全量分页或 App 收藏快照 |
| 加入远端收藏 | 不支持 | 尚未接入官网设备校验流程 |
| 移出远端收藏 | 部分支持 | Web 删除后回读确认；App 删除未实现，真实写入未实测 |
| 搜索 | 部分支持 | 匿名 App 搜索，仅第一页 |
| 分类书城与榜单 | 支持 | 动态频道、分类、时代、类型、资费、状态和排序；保留旧榜单 |
| 详情与目录 | 支持 | 保留章节顺序，卷标题和锁章不当作可读章节 |
| 免费正文 | 支持 | 匿名读取 |
| 已购 VIP 正文 | 已实现，未实测 | 按所选 Web 或 App 协议读取，不解锁未购章节 |
| 章节与全本缓存 | 支持 | 已缓存目录和正文可离线续读、重开 |
| 阅读进度同步 | 不支持 | 仅本地保存，未接入可验证的远端写回 |
| 笔记与统计同步 | 不支持 | 仅本地保存 |
| 整书书评 | 不支持 | 未找到可验证的独立整书接入接口 |
| 章评与段评 | 支持 | 按章／段归属，支持分页、定位和离线缓存 |
| 评论表情 | 支持 | 官网表情原位显示；离线缺图保留文字标记 |
| 评论回复与写操作 | 不支持 | 未接入回复分页、发评、点赞或删评 |
| 账号切换 | 部分支持 | 不允许直接换凭据；须先退出清理旧本地数据，未同步记录会丢失 |
