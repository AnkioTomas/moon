# 晋江文学城

## 能力与边界

| 功能 | 当前实现 |
| --- | --- |
| 登录 | 手机 Web Cookie 粘贴、浏览器扩展回传；保留 App 账号密码与手机／邮箱设备验证入口。密码仅用于当次提交，不落盘，旧配置中的密码首次访问 App 登录态时移除。 |
| 书架 | Web 收藏全量分页拉取；App 增量收藏接口按完整快照拉取。支持本地隐藏／删除；Web 删除上行后重新读取收藏确认，App 删除上行尚未实现。 |
| 加入收藏 | 未实现。官网收藏存在设备校验，不能把插件缺能力说成官网没有接口。 |
| 搜索／发现 | 匿名 App 搜索第一页；官网高级分类库、频道、原创／衍生、时代、类型、资费、状态与排序；保留旧榜单节点。分类选项来自当前官网表单，不维护本地分类编号表。 |
| 目录／正文 | 匿名 App 元数据、目录和免费章正文。维持原有章节 uid／索引与目录缓存版本；已购 VIP 章走所选 Web 或 App 协议，不代购、不解锁未购章。 |
| 评论 | Web 段评与真正章评，按章节 ID 与 `paragraph_id` 区分；`-2` 为章评，其余正数为段序。复用公共评论列表、缓存与页内标记；不把章评复制成整书书评。整书书评和回复分页本轮未接入可验证接口。 |
| 进度／笔记／统计 | 本地保存。最近阅读页能显示位置，但尚无已验证的进度写回；不提供仅拉不推的虚假同步。笔记、统计未接远端接口。 |
| 离线 | 已缓存章节、目录、进度和评论可用；未缓存正文／评论明确报网络错误，不把失败落成成功缓存。 |

分类每批默认最多 60 本，屏幕分页由宿主决定；中间页失败、重复页或分页归属错误均报错，不交付成功形状的半截列表。筛选沿用宿主分组控件，溢出项有频道／分类／价格／状态／排序等名字。

评论支持官网目录的 95 种表情（含橘糖、紫糖、七彩心／裤子），按 `[表情名]` 在文字原位置显示图片；只加载当前评论用到的素材，复用主题图片缓存。不把表情放到卡片配图栏，普通 Unicode emoji 和未知标记原样保留。旧离线评论缓存也补映射；没有缓存图片时保留文字标记。表情目录核对于 2026-11-08，来源为匿名 `GET www.jjwxc.net/app.jjwxc/Pc/Emoji/getList`，磕糖目录的两项与普通目录一致；素材位于 `i9-static.jjwxc.net/tmp/emoji/`，请求不附带书源凭证。

评论中的 HTML 标签和实体统一转成纯文本：`<br>`、`&lt;br&gt;` 等显示为正常换行，不将标签直接展示给读者。旧离线缓存读取时同样处理，不改变评论语义，也不清空缓存。

该 CDN 会对 PNG 返回 `Content-Encoding: gzip`，即使请求声明 identity；主题图片下载器按实际响应头解压后才写入图片缓存，坏压缩响应报错并清理临时文件。独立无账号模拟器已确认狗头、紫糖、橘糖、红心、紫裤和加油六种表情实际下载、解码并在评论卡片原位置绘制；相关回归 8 个文件、411 条断言通过。

## 协议与接口

这不是纯 Web 源：保留现有匿名及登录 App 接口，同时用官方手机 Web 分类／收藏／VIP 正文、电脑 Web 评论。公共分类、封面、元数据、目录与免费正文不附带账号 Cookie。

Web 收藏／VIP 请求只发送手机站 Cookie。电脑端登录可在电脑浏览器打开手机站取得对应请求头；父域 `.jjwxc.com` Cookie 可用于手机站，`.jjwxc.net` 不因此变成 `.jjwxc.com` Cookie。电脑评论保留原有协议认证方式（Web Cookie／App token）；跨域登录有效性本轮未实测，不能承诺两套 Cookie 自动互通。

## 本地与账号

本地 sqlite／文件是唯一真相。删除先清缓存、写墓碑，立即从书架消失；联网后由公共推脏队列尝试 Web 上行。失败保留墓碑重试；App 协议删除未实现，不会伪造成功撕掉墓碑。未配置账号时遵循基类纯本地删除逻辑。

本轮未取得可验证的稳定账号 ID，因此**拒绝直接用不同 Cookie 或另一套登录覆盖现有账号**，保留旧有效登录和本地数据。同一 Cookie 可重新校验；要换号或更换已失效的 token／Cookie，先使用设置里的“退出登录”，确认清除此源本地书架、进度、笔记和缓存（包括未同步记录），再登录。退出不删除远端收藏；不静默清库，也不把旧书架标脏推到新账号。历史配置曾同时保存的两套协议不能证明属于同一账号，使用前应先退出再登录。

token 过期不再依靠落盘密码自动重登；此行为是有意改变。暂时网络失败不使登录过期，旧 Cookie／token 的迟到失效响应不能注销新登录。密码登录窗口可取消，关闭后迟到回包不保存。

## 核对与限制

最近核对：2026-11-07。匿名官网已验证分类表单、资费／频道／状态选择、不同分页及稳定封面；真实免费章评论数包含 `-2`，章评第 1 页 20 条、第 2 页 17 条、总数 37。测试只记录数量与响应结构，不保存读者资料或正文。

本轮独立模拟器使用专用数据目录，未复用用户配置：分类聚合 60 本、8 个筛选分组，截图确认筛选两行、每屏 8 本、共 8 页并可翻到第 2 页；搜索返回 20 本，目录 27 章，免费正文可排版。57 个段评热点全部定位成功，37 条章评按 20／17 两页读取。缓存前两章均成功，断网后用 CREngine 阅读第一章、下一章及关书重开均通过，章末评论锚点存在；恢复联网后另发不缓存的真实请求确认成功。封面地址另经匿名 HTTP 请求确认返回 JPEG。

离线用例覆盖分类解析／分页／超量截断／错误／取消、段评与章评分流及章节归属、坏评论响应、收藏读回确认、重复页拒绝、旧登录竞态、密码不落盘和登录取消；相关回归 11 个文件、711 条断言通过。晋江实现的 13 个 Lua 文件经完整根依赖解析的定向 LuaLS 检查无问题；全仓库检查发现其他源及功能的无关告警，不代表全仓库零告警。单测不能代替真实账号验证。

本轮未使用真实账号，密码／设备验证码提交、扩展握手、已购 VIP、远端增删和进度写回未实测。没有授权修改用户远端书架、发评、点赞或购买；未绕过数美、验证码或付费权限。整书书评、回复和扫码登录不能仅凭页面名称或猜测参数宣布支持。
