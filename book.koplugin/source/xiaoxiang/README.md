# 潇湘书院

| 能力 | 是否支持 | 备注 |
| --- | --- | --- |
| 扫码登录 | 已实现，未实测 | 阅文二维码，使用 QQ阅读或起点 App；最终账号登录未完成实测 |
| 浏览器登录与 Cookie 导入 | 已实现，未实测 | 保留扩展回传和手动粘贴入口 |
| 设备密码与验证码登录 | 不支持 | 可在官网完成登录后导入 Cookie |
| 书架拉取 | 支持 | 仅根书架图书，不枚举其他文件夹或资源类型 |
| 书架新增与移出 | 已实现，未实测 | 本地先生效，同步上行后回读确认；失败保留脏行或墓碑 |
| 搜索 | 支持 | 聚合后续页，默认最多 60 本 |
| 分类书城 | 支持 | 动态分类、标签、排序、资费、状态、更新时段和字数筛选 |
| 榜单 | 部分支持 | 潇湘票、畅销、完结、阅读、收藏；旧移动榜单仅单页 |
| 详情与分卷目录 | 支持 | 保留章节顺序和长整数 ID |
| 免费正文 | 支持 | 可匿名读取 |
| 已购正文 | 已实现，未实测 | 按官网权限解码；未购预览不作为正文缓存 |
| 章节与全本缓存 | 支持 | 支持预取和后台缓存；整本下载未完成实测 |
| 离线阅读 | 支持 | 已缓存章节可续读、关书重开 |
| 阅读进度同步 | 部分支持 | 仅章节位置，无章内比例；远端写入未实测 |
| 笔记与统计同步 | 不支持 | 仅本地保存 |
| 书评、章评、段评与回复 | 不支持 | 当前 Web 协议未找到可验证接口，不代表 App 没有评论 |
| 账号切换 | 部分支持 | 同账号可续期；换号须确认清理旧本地数据，未同步记录会丢失 |
