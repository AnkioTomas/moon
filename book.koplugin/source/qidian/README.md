# 起点中文网

使用起点官方移动 Web 与阅文 Web 登录协议，不使用 App 私有接口。电脑浏览器 Cookie 登录入口继续保留。

## 登录与账号安全

扫码确认后必须完成官方 `302url` 或 `ticket` 的起点站点兑换，再校验账号，不能凭轮询 JSON 中的 `ywGuid/ywKey` 就结束。第三方扫码域不发送起点 Cookie，兑换只允许已核对的官方主机，收集全部 `Set-Cookie`。

短信流程使用独立候选会话。图片挑战与短信分别保存自己的 `sessionKey`；发送前确认协议，成功发送后冷却 60 秒。验证码桥仅短期开放必要动作，不向浏览器提供手机号、短信码或账号 Cookie。失败、取消和迟到回调不覆盖原有效登录，也不保存手机号或验证码。

账号身份取校验页的稳定 GUID，不拿昵称或 Cookie 是否变化判断换号。同账号续期保留本地数据；旧配置缺账号 ID 时先验证旧 Cookie 迁移。无法确定旧账号身份时阻止直接覆盖。真正换号必须确认清理旧本地书库、缓存、进度和笔记，包括未同步记录；先结束阅读及旧任务，不把旧数据推到新账号。清理失败不保存新账号并恢复旧登录，不承诺已经清理的文件能自动恢复。退出同时清凭证与账号 ID。

## 公开协议概览

公共浏览接口不携带账号 Cookie；匿名 `_csrfToken` 同时放入 Cookie 与参数。书架、购买权限及进度使用已保存的起点登录。字体不携带账号 Cookie；登录与验证码响应不缓存。

| 用途 | 方法／主机与路径 | 关键结构 |
| --- | --- | --- |
| 扫码 | 阅文官方轮询与起点兑换；起点 `appId=13, areaId=31, ticket=1` | 扫码状态、`302url`／`ticket`，最终站点 Cookie 后再校验 |
| 短信初始化 | `GET ptlogin.yuewen.com/userSdk/getvalidatecode` | JSON、`sessionKey`、`imgSrc`、挑战标志 |
| 短信发送／登录 | 同主机 `/userSdk/sendmsgnew`、`/userSdk/phonecodelogin` | 前者号码含国际区号，后者按官网提交手机号；图形 proof 与短信码使用各自会话 |
| 腾讯挑战 | 官方 `turing.captcha.qcloud.com/TCaptcha.js` | 按官网顺序提交 `randstr;ticket`，不使用浏览器账号 Cookie |
| 登录校验 | `GET m.qidian.com/bookshelf/my/` | SSR 登录标志及 `user.guid`；身份缺失、失效和网络失败分别处理 |
| 书架 | `GET /webcommon/bookshelf/mlist` | `gid/pageNum/pageSize`；成员、分组、末页 |
| 新增／删除 | `POST /webcommon/bookshelf/addbooks`、`GET /webcommon/bookshelf/delbook` | `bookId` 或 `bids/gid`，登录 CSRF；不是仅看 HTTP 200 |
| 分类目录 | `GET /category/`、`/category/catid<id>/` | `info`、动态 `filters/orderBy` |
| 分类分页 | `GET /webcommon/category/list` | `gender/catId/subCatId/orderBy/isvip/size/isfinish/sign/update/pageNum`，`records/pageMax` |
| 榜单分页 | `GET /webcommon/rank/<key>list` | `catId/gender/pageNum`；`readindex` 转为 `readIndex`，`records/isLast` |
| 搜索分页 | `GET /webcommon/search/list` | `kw/pageNum`；`bookInfo.records/isLast` |
| 详情／目录 | `GET /book/<id>/`、`/book/<id>/catalog/` | SSR `bookInfo`、`vs[].cs[]` |
| 正文 | `GET /chapter/<book>/<chapter>/` | `isBuy/vipStatus/fEnS/cES`，本次响应的用户 GUID 与解密输入 |
| 进度 | `POST /webcommon/chapter/updReadStatus` | 章节 ID、标题、VIP 状态、更新时间；当前接受 `code=0`，真实写后回读未实测 |
| 评论 | `GET /webcommon/chapterreview/reviewsummary4m`、`/reviewlist4m` | 书／章／段 ID；`-1` 是章末；列表按 `isEnd/size/空页` 结束 |
| 书友圈预览 | `GET /readersCircle/<book>/` | SSR `bookCirclePostCount/bookCirclePostList`（最多三条）；不是每章评论或完整回复 API |

网络故障、坏响应和匿名风控不当成空列表或账号失效；账号请求过期才提示重新登录。异步操作返回现有取消句柄。

## 本地与同步

本地库和文件是阅读真相。新增、进度与删除先本地生效，由现有脏同步收敛；删除清本地缓存并留墓碑，远端确认后才移除书籍行，失败保留待同步状态。账号换号清理不发送远端删除。

保持原书籍身份、章节路径及目录缓存。取消原先按字体迁移标记批量删除章节 HTML 的行为；本次 VIP 修复不靠清缓存。启用章评后，仅在新 HTML 和复用旧缓存时追加章末区域，替换失败保留原文件并报错。

已登录官方浏览器中，一章用户已购 VIP 经官网原生 Fock 解码成功；只核对状态与长度，不导出 Cookie、身份或正文。未购买反馈书的其他章节。
