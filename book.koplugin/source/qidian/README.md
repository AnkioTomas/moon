# 起点中文网

| 能力 | 是否支持 | 备注 |
| --- | --- | --- |
| 扫码登录 | 支持 | 完成官方站点兑换后再校验账号；新扫码已购流程仍需实测 |
| 手机短信登录 | 已实现，未实测 | 支持图片验证码及腾讯验证桥，安全验证由用户完成 |
| 浏览器登录与 Cookie 导入 | 支持 | 支持扩展回传及手动粘贴 |
| 设备密码登录 | 不支持 | 短信登录不是密码登录 |
| 书架拉取 | 支持 | 分组、分页及书号去重 |
| 书架新增与移出 | 已实现，未实测 | 本地先生效，联网后推送；远端写入回读未完成 |
| 分类书城 | 支持 | 男／女频、子分类、资费、字数、状态、签约、更新时间和排序 |
| 榜单与搜索 | 支持 | 七种榜单；列表默认聚合 60 本，搜索最多 200 本 |
| 详情与分卷目录 | 支持 | 保留章节 ID 和已有目录缓存 |
| 免费与已购正文 | 支持 | 按官网权限解码，不购买或绕过权限 |
| 章节与全本缓存 | 支持 | 已缓存章节可离线打开；未购提示不计入正文缓存 |
| 阅读进度同步 | 部分支持 | 仅章节位置，无章内比例；远端写后回读未实测 |
| 笔记与统计同步 | 不支持 | 仅本地保存 |
| 整书书友圈 | 部分支持 | 详情展示最多三条帖子预览，不是完整列表 |
| 章评与段评 | 支持 | 真正章末评论与段落评论共存，支持定位、分页及缓存 |
| 评论回复 | 部分支持 | 仅服务器附带的二级预览，可本地翻阅；没有完整回复分页 |
| 评论写操作 | 不支持 | 不发评、不点赞、不删评 |
| 账号切换 | 部分支持 | 同账号可续期；换号须确认清理旧本地数据，未同步记录会丢失 |
