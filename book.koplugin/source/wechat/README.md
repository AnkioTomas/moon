# 微信读书

| 能力 | 是否支持 | 备注 |
| --- | --- | --- |
| 微信扫码登录与续期 | 支持 | 使用官方扫码及登录令牌流程 |
| 书架拉取 | 支持 | 全量／增量同步、分组、变更详情补齐；大快照支持浏览器分批导入 |
| 书架新增与移出 | 支持 | 本地先生效，联网后推送；真实账号端到端回读未完成本次验证 |
| 详情与目录 | 支持 | App 接口读取书籍和章节元数据 |
| 正文下载与阅读 | 支持 | EPUB／TXT 包本机解包，受账号阅读权限限制 |
| 搜索与分类书城 | 支持 | App 搜索、公开 Web 分类和分类书单；不是完整 App 书城复刻 |
| 阅读进度同步 | 支持 | 开书比较云端位置；本地先落盘，阅读中合并推送，离线保留待同步数据 |
| 阅读时长同步 | 支持 | 上传本地采集时长及补报数据 |
| 维持官网「在读」状态 | 已实现，未实测 | 零时长 Web 心跳，不重复增加阅读时长 |
| 划线与想法同步 | 支持 | 走属主书籍的注解接口 |
| 整书书评与独立章评 | 不支持 | 未接入可验证接口，不能把其他书籍的想法当作属主书评 |
| 段评与回复 | 支持 | 按章节及文本范围定位，使用公共评论标记和列表 |
| 离线阅读 | 支持 | 已下载内容和本地记录可用；联网后再同步 |
| 账号切换 | 部分支持 | 游标按账号作废；旧本地书架不自动清理，不是完整账号分区 |
