# 京东读书

| 能力 | 是否支持 | 备注 |
| --- | --- | --- |
| 京东 App 扫码登录 | 部分支持 | 兑换后校验书架；需要安全验证时明确拒绝，尚不能在验证后续接原扫码会话 |
| 浏览器扩展登录 | 已实现，未实测 | 官网完成登录后回传；需要浏览器扩展握手 |
| 书架拉取 | 支持 | 读取排序并分批补齐详情 |
| 书架新增与移出 | 已实现，未实测 | 本地先生效，联网后推送，失败保留脏行或墓碑 |
| 搜索与书城 | 支持 | 搜索、分类及不同周期榜单 |
| 详情与目录 | 支持 | EPUB、TXT 网文目录，按源站分页获取 |
| 免费与已购正文 | 部分支持 | 受试读、购买和会员权限限制；真实账号阅读未完成实测 |
| 章节缓存与离线阅读 | 支持 | 仅已缓存内容，未缓存正文需要联网 |
| 阅读进度同步 | 部分支持 | 章节及全书比例；本地 HTML 不对应远端段落坐标 |
| 笔记与统计同步 | 不支持 | 仅本地保存 |
| 整书书评 | 部分支持 | 匿名首批 20 条预览，整书缓存不随切章复制；界面没有远端续页入口 |
| 章评、段评与回复 | 不支持 | 当前 Web 协议未找到可验证接口，不代表 App 不支持 |
| 评论写操作 | 不支持 | 不发评、不点赞、不删评 |
| 账号切换 | 不支持直接隔离 | 须先退出清理旧数据，未同步记录会丢失 |
