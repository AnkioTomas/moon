# 快看漫画

| 能力 | 是否支持 | 备注 |
| --- | --- | --- |
| 微信扫码登录 | 支持 | 独立候选会话，保存前校验账号 |
| 密码与短信登录 | 已实现，未实测 | 手机扫码完成腾讯安全验证；新登录完整链路未分别验证 |
| 浏览器登录与 Cookie 导入 | 支持 | 手动粘贴或扩展回传，扩展完整握手未实测 |
| 书架拉取 | 支持 | 分页读取官网收藏 |
| 书架新增与移出 | 已实现，未实测 | 本地先生效，写后完整回读；失败保留脏行或墓碑 |
| 搜索与分类书城 | 支持 | 动态题材、地区、资费、状态和排序，默认聚合 60 本 |
| 详情与完整目录 | 支持 | 保留作品及每话 ID、官网顺序和缓存路径 |
| 免费与已购漫画 | 支持 | 以服务端权限为准，下载为 CBZ；未购明确拒绝 |
| 章节与全本缓存 | 支持 | 已完成话可复用，失败可重试；整部作品下载未实测 |
| 离线阅读 | 支持 | 已缓存 CBZ、目录及本地位置可用 |
| 阅读进度同步 | 部分支持 | 回读只能确认话 ID，不支持云端页内比例；本地页内位置保留 |
| 笔记与统计同步 | 不支持 | 仅本地保存 |
| 独立整书书评 | 不支持 | 详情「书评」实际是话题页的首话评论，窗口明确标注 |
| 每话章评 | 支持 | 开启「章节评论」后在 CBZ 末页显示，支持分页、切话隔离和离线缓存 |
| 段评 | 不支持 | 当前 Web 协议未找到段落定位接口 |
| 评论回复与写操作 | 不支持 | 未接回复分页、发评、点赞或删评 |
| 账号切换 | 部分支持 | 同账号可续期；换号须先退出清理旧数据，未同步记录会丢失 |
