# 快看漫画

最近核对：2026-11-07。接入的是快看电脑 Web 协议，不使用 App 私有接口。

## 当前能力

| 功能 | 实现与边界 |
|---|---|
| 搜索 | 官网作品搜索；无需登录 |
| 书城 | 官网分类库，动态读取题材；支持地区、价格、连载状态、排序；按调用方数量聚合多页并去重，默认最多 60 本 |

| 笔记、统计同步 | 未实现远端同步；本地记录保留，不标成云端成功 |

## 登录与账号边界

官网电脑登录页为 `https://www.kuaikanmanhua.com/webs/loginh`。公开页面和脚本包含密码、短信验证码，以及微信、QQ、微博入口；设备已接微信扫码、手机号密码与短信登录。密码相关接口使用加密字段，安全验证由浏览器加载腾讯官方控件完成，不绕过验证，也不自动解题。

在月读打开「设置 → 书库 → 账号 → 快看漫画」：

1. **微信扫码：**点账号行，用微信扫一扫并在手机上确认；支持等待、已扫码、确认、拒绝、过期、重新获取和关闭，5 分钟截止。每次登录有独立匿名 Cookie 和取消句柄，关闭后停止请求与轮询。仅走快看官方初始化、微信开放平台和已核对的快看回调，不把快看 Cookie 发送到微信。
2. **密码登录：**点「密码登录」，在设备填国际区号、手机号与密码，阅读并同意官网协议；用同一 Wi-Fi 下的手机扫描安全验证二维码，按腾讯控件提示完成验证。设备将手机号和密码按官网 AES-256-CBC/PKCS7 加密，以表单提交官方密码接口，随后独立查账号确认。密码按原值处理，不保存密码，也不套旧版的字符或长度限制。失败后可回设备修改输入，不自动重复尝试错误密码。
3. **短信登录：**点「短信登录」，填区号与手机号，点「获取验证码」并同意协议，扫码完成安全验证；只有官网发送接口业务成功才提示已发送。回设备输入收到的短信码并登录。重发间隔 60 秒，验证码只能提交给本次成功发送的手机号。浏览器不接收手机号、密码或短信码，只有临时访问票据和腾讯验证凭据；票据五分钟有效，关闭、超时或完成后作废。腾讯可能出滑块或点选题，以官方控件提示为准。需启用远程管理功能，服务会按现有远程页面入口自动启动。
4. **电脑浏览器：**仍可在官网登录，用官方密码、短信或第三方授权完成登录和腾讯验证；再在月读远程管理网页的「浏览器登录」里授权「快看漫画」（需要 moon-cookie-storage 扩展）。扩展通过账号 JSON 中 `data.user_info.authenticate=1` 等待成功，回传后设备仍独立校验；设备密码/短信入口不依赖该扩展。
5. **粘贴 Cookie：**官网登录后打开账号校验地址 `https://www.kuaikanmanhua.com/v2/pweb/user_info/get`，按 F12 打开「网络」，刷新页面，复制该请求标头里的完整 Cookie，回到账号页点「粘贴 Cookie」。不要把密码、短信码或 Cookie 发到聊天。

只有账号接口业务 `code=200`、`authenticate>0` 且存在有效的稳定 `user_id` 才保存 Cookie、账号 ID 与已登录标记；不保存密码、验证码或微信授权码。失败、网络故障、取消和旧请求迟到均不覆盖旧登录，网络故障不注销账号。Cookie 失效可重新扫码或导入。

本地书库仍以源与作品 ID 区分，不按快看账号隔离。已校验的不同账号不能直接覆盖：先点「退出登录」，明确确认清除该源的本地书架、进度、笔记和缓存，再登录新账号；这不是删除官网收藏。退出会取消在飞同步。旧配置缺少账号 ID 时先校验原 Cookie；仍有效则记录其稳定账号 ID、默认同步，无需新增开关。续期时，旧 Cookie 与新会话须可验证为同一账号；原 Cookie 已失效且无法确认身份时保留旧配置并明确要求退出旧登录，不能把未知旧账号的脏记录自动推给新账号。

**没有独立的云端同步开关。** 登录后按宿主默认行为走公共书架、进度和 `pushDirty` 队列，账号边界在登录及每次请求前校验，不额外要求用户启用同步。

## Web 接口概览

主域为 `www.kuaikanmanhua.com`，公开脚本来自 `static3w.kuaikanmanhua.com`，图片由接口返回的官方 CDN URL 提供。公共搜索、分类、话题页与评论请求不发送账号 Cookie；收藏及页图请求仅向官网主域发送旧配置 Cookie，图片 CDN 不接收它。

| 用途 | 方法与路径 | 参数与响应要点 | 登录要求 |
|---|---|---|---|
| 搜索 | GET `/search/web/complex` | `f=3&q=<关键词>`；`code=200`，`data.topics.hit` | 无 |
| 分类库 | GET `/search/mini/topic/multi_filter` | `page,size,tag_id,label_dimension_origin,pay_status,update_status,sort`；`hits.topicCategories`、`hits.topicMessageList`、`total` | 无 |
| 详情、目录 | GET `/web/topic/<topic_id>/` | HTML 中 `topicInfo`、`comics`、作者昵称；不执行网页 JavaScript | 无 |
| 页图挑战 | GET `/v1/aegis/api/web/challenge` | `callback`；临时 `kk_s_t`，按公开网页算法构造 `answer`；不缓存响应 | 无 |
| 页图 | GET `/v2/pweb/comic/<comic_id>` | `source,answer`，请求头 `width: 564`；`data.comic_info.comic_images`，优先 `url1280`；`locked=true` 表示无阅读权限 | 免费话无需登录；付费话须有效权限 |
| 评论 | GET `/v2/comments/comic/<comic_id>/order/score` | `offset,limit=50,total=true`；`data.comments,total`；只展示 `replied_comment_id=0` 的主楼 | 无 |
| 收藏列表 | GET `/v2/pweb/fav/topics` | `since` 是记录偏移量，`limit=20`；`data.topics,total`；按实际返回行数推进偏移，完整拉取后才对账，不把坏页或重复整页当作末页 | 先独立校验账号；同轮所有分页使用同一 Cookie |
| 账号校验 | GET `/v2/pweb/user_info/get` | `code=200`；`data.user_info.authenticate,user_id`；未登录时 authenticate=0 | 是 |
| 密码登录 | POST `/v2/passport/pc/v2/mobile_pwd_login_encrypted` | AES 加密的 `phone,password`，`remember=1,ticket,random,verify_provider=tencent`；form 编码；业务成功后另查账号，不直接信任登录回包 | 腾讯验证 |
| 发送短信 | POST `/v2/passport/pc/v2/get_sms_code` | `phone,ticket,random,verify_provider=tencent`；手机号格式 `+86-<号码>`，国际区号保留 `+`；业务 `code=200` 后才允许本次短信登录 | 腾讯验证 |
| 短信登录 | POST `/v2/passport/pc/mobile_code_login` | `phone,code,remember=1`；与发送短信共用匿名 Cookie，业务成功后独立查账号 | 短信码 |
| 腾讯安全验证 | 官方 `TJCaptcha.js` + 设备 `/api/kuaikan_verify/config\|verify` | 官方 appid `2034681882`；浏览器只提交腾讯 `ticket,randstr`，设备映射成 `ticket,random`。拒绝脚本加载失败的 `trerror_` 应急票据 | 五分钟设备票据 |
| 微信扫码初始化 | GET `/v1/passport/login/pc/user_wechat_login` | `redirect_uri`；匿名 Cookie、302 到微信 `qrconnect`；检查 appid、scope、官方回调和 state | 无 |
| 微信码与轮询 | GET 微信 `/connect/qrconnect`、`/connect/l/qrconnect` | UUID；408 等待、404 已扫、405 确认、403 拒绝；不发送快看 Cookie、不缓存 | 微信确认 |
| 微信授权回调 | GET `/v1/passport/login/pc/user_wechat_login_check` | `code,state`；合并官网会话 Cookie，仅跟随官网 HTTPS 跳转，再校验账号 | 微信确认 |
| 收藏修改 | POST / DELETE `/web/topic/<topic_id>/fav` | 匿名挑战取得新 `kk_s_t`，签名 `answer` 放 query，官网请求才带账号 Cookie；业务 `code=200` 后完整回读收藏，确认存在/缺席才成功。限量人工写入实测尚未完成 | 是 |
| 进度上报 | POST `/v2/pweb/read/history/report` | form 字段 `view_rate` 是 **记录数组** 的 JSON，单条含 `topic_id,comic_id,total_count,read_count,max_read_count,read_time,max_read_count_time`；时间单位毫秒，不是作品 ID 到百分比的 map。写后回读话 ID，不据此声称章内比例已回读验证 | 是 |
| 阅读历史 | GET `/v2/pweb/read/history/list` | `since,limit=20`；`data.topics,total`。`topic_id,comic_id` 映射连续章号；`read_count` 是已读话数，不能当图片页码。无记录返回 empty，坏响应报错；云端话不在缓存目录时刷新一次 | 是 |

评论需要官网公开请求头 `User-Agent-PC: PCKuaikan/1.0.0/100000(...)`；只有普通 UA 时本次实测返回 `code=400, message="bad request"`，补齐后返回 `code=200`。HTTP 200 不等于业务成功：坏 JSON、缺字段、网络失败返回错误，不包装成空列表。缺失页图不生成半本 CBZ。旧 Cookie 中的 `kk_s_t` 不覆盖本次挑战的新值。

分类编码来自官网：地区 1/2/3/4 为全部/国漫/韩漫/日漫；价格 0/1/2/3 为全部/免费/付费/VIP 抢先看；状态 0/1/2 为全部/连载/完结；排序 1/2/3 为推荐/最火热/新上架。题材 ID 则动态读取，不维护静态分类表。筛选由现有分组控件折叠展示。

官网本次每页请求 48 本，部分页实际返回 47 本；是否继续按 `total` 与请求页码判断，不因少一行提前终止。聚合使用公共 `source.browse`，中间页失败整体报错，取消后不回调。屏幕每页数量由宿主决定，不在源里硬编码。

## 本地操作与同步

加入作品先写本地并标脏，立即生效。删除先清缓存、写墓碑并从书架隐藏，删除入口不直接发网络请求。登录后公共 `source.shelf` 默认先推删除、拉收藏、推新增、必要时再拉并对账；仅远端删除已确认才撕墓碑。进度沿 `book.progress` 上行并按推送时修订号确认，不覆盖同时产生的新进度。失败保留墓碑/脏进度并报告 `push_error`，现有可恢复后台队列重试；取消或换账号后的迟到结果不确认本地数据。手动标已读而无页数时先查末话页图数量，未购买或查询失败不伪造成功。

未登录时本地操作仍生效，脏行与墓碑保留，不拿匿名空收藏对账。完整收藏快照才对账，空快照不整架下架。官网历史不是收藏成员，不把历史作品自动加入书架。笔记和统计仍只保存在本地。

章节、缓存与在飞句柄归本次操作所有；关闭或取消只取消当前阶段。已缓存的旧 CBZ 优先复用，离线打开不强制刷新目录。匿名目录里的锁定状态不是账号购买状态，下载时重新由服务端确认权限。
