# 知乎盐选

源 ID：`zhihu`。说明核对：2026-11-07，基于本目录当前实现。

## 当前可以做什么

- 用知乎 App 扫码登录，或从电脑浏览器授权／粘贴 Cookie；新会话通过账号接口校验后才保存。
- 浏览推荐、热搜、热度、口碑、长篇榜及接口返回的分类筛选；搜索盐选内容，搜索可能需要登录并受风控限制。
- 读取短篇详情和长篇专栏详情、评分、分页目录；保留章节顺序和稳定身份。
- 在账号有权限时读取完整正文；按网页协议恢复动态字体，未购买或折叠的预览不当作完整正文缓存。
- 短篇整篇转为本地 EPUB，长篇按章节阅读；缓存章节或全本，已经保存的正文可离线阅读。
- 登录后读取和上传阅读进度。
- 开启书源设置中的「显示段评」后，在章节末尾显示**章节评论**入口、数量和列表，支持根评论分页、回复分页及评论表情显示。

## 当前不能做什么

| 项目 | 原因与实际边界 |
|---|---|
| 同步知乎云端书架、收藏或购买列表 | 当前适配没有可对账的云端书架接口，`shelf_push=false`；月读书库保留本地加入／打开的记录，不代表知乎的收藏或购买列表 |
| 将本地增删上传为知乎加入／移出书架 | 没有接入上行接口；删除只在本地生效，不操作知乎网站内容 |
| 按正文每个段落定位评论 | 已接入的是绑定盐选章节 ID 的章评，不是逐句／逐段热点；设置沿用公共「显示段评」名称，不能据此理解为逐段评论 |
| 发布、点赞或删除评论 | 当前只提供读取评论与回复，没有接入评论写操作 |
| 在插件里用手机号密码登录 | 插件提供 App 扫码与电脑 Cookie；其他登录方式请在知乎官方网页完成 |
| 云端笔记／阅读统计同步 | 没有实现对应接口，本地划线与统计不代表上传到知乎 |
| 绕过会员、购买或安全验证 | 站点权限与风控限制；折叠、无权限的正文明确提示，不缓存试读内容冒充全本 |
| 直接换账号并隔离所有本地数据 | 本地身份没有账号维度，不提供按账号保存的独立书库、进度和缓存 |

换账号前应关书、退出旧账号，再登录新账号。退出确认会清除本机该源的书库及依附数据，未同步的本地记录也可能丢失；清理不等于删除知乎网站上的内容。

## 协议与登录边界

使用知乎网页实际调用的 **Web HTTP／JSON 协议**，不是直接解析盐选预览 HTML：

- `https://www.zhihu.com`：登录、账号校验、网页搜索及安全验证流程。
- `https://api.zhihu.com`：榜单、专栏、目录、正文、阅读进度和评论。
- `https://captcha.zhihu.com`：官方安全验证；不是付费内容接口。
- 正文按当前站点协议生成 `x-zse-93`／`x-zse-96` 签名；请求带必要的网页请求头和账号 Cookie。签名不替代账号权限。
- 动态字体按正文响应提供的信息恢复；失败作为正文失败返回，不保存乱码。
- 榜单可以匿名读取。搜索受登录／风控影响，付费正文和进度需要有效账号及对应权限。
- 扫码使用独立匿名会话处理 Cookie、状态和验证；失败或取消不覆盖旧账号，不保存登录密码。HTTP 401 在请求会话仍匹配时标记登录失效，普通网络失败不等于登出。

## 接口概览

`WEB` 指 `www.zhihu.com`，`API` 指 `api.zhihu.com`。ID、Cookie、令牌与游标均为运行时值，下面不包含真实账号数据。

| 用途 | 方法／主机／路径 | 关键参数与语义 |
|---|---|---|
| 登录入口 | `GET WEB /signin` | 建立扫码匿名会话；按响应处理官方安全验证跳转 |
| 获取登录二维码 | `POST WEB /api/v3/account/api/login/qrcode` | JSON 创建请求；返回二维码令牌、链接及有效期 |
| 扫码状态 | `GET WEB /api/v3/account/api/login/qrcode/<token>/scan_info` | 保持同一匿名会话；处理等待、确认、过期和安全验证 |
| 账号校验 | `GET WEB /api/v4/me` | 拟保存的 Cookie；有效响应须有用户标识，失败不替换旧会话 |
| 盐选搜索 | `GET WEB /api/v4/search_v3` | `t=km_general`、`q`、`offset=0`、`limit=20`，使用网页版本请求头 |
| 榜单与筛选 | `GET API /km-vip-zhihu-web/vip_tab/svip_story` | `modules=billboard`、`billboard_type`、`billboard_filter`、`offset=0`、`limit=10`；当前不是无限翻页书城 |
| 长篇专栏详情 | `GET API /remix/paid_columns/<column>` | `is_new_column=true`、`is_web=true`；也用于获取上次阅读章节 |
| 专栏评分 | `GET API /darwin/sku_grading/<sku>` | 来自详情的 SKU；评分失败会记录错误，但保留已取得的详情 |
| 长篇分页目录 | `GET API /remix/well/<column>/catalog` | `order_by=global_idx`、`limit=50`、`offset`；根据响应分页字段继续拉取 |
| 短篇详情 | `GET API /remix-web/paid_columns/<column>/sections/<section>/manuscript/simple` | 取得单篇元信息和章节信息 |
| 正文及章内进度 | `GET API /remix-web/paid_columns/<column>/sections/<section>/manuscript` | `v=1`、`manuscript_version=0`、网页签名；检查 `is_fold`、`authentication_result`、`manuscript`、`use_font` |
| 进度上传 | `POST API /promus/progress` | JSON 数组：章节 `unit_id`、`type=paid_column`、`progress`、`client_updated_at`、`is_finished`；只认 `success=true` |
| 章节根评论 | `GET API /comment_v5/paid_column_section_manuscripts/<section>/root_comment` | `limit=20`、`order_by=score`、`offset`；归属是章节 ID，不是段落坐标 |
| 评论回复 | `GET API /comment_v5/comment/<comment>/child_comment` | `limit=5`、`order_by=ts`、`offset`；后续游标原样传回，不猜测数值页码 |

## 本地、离线与同步

- 长篇身份为专栏 ID；短篇为 `专栏ID/章节ID`。短篇 EPUB 内部目录是本地转换结果，不是知乎的远端章节编号。
- 书库、路径、阅读记录先落本地。没有云端书架的拉取／增删编排，不能把本地书库称作双向同步书架。
- 删除清理本地文件并标删，没有知乎远端移出确认流程；不会请求删除知乎上的文章或专栏。
- 目录保存在本地；缓存版本兼容时直接复用。已缓存正文可离线打开，未缓存正文、搜索、榜单和新评论仍需要网络。
- 长篇进度按远端章节及章内比例同步；短篇按整篇比例同步，不能把 EPUB 内部小节序号传到云端。
- 进度上传失败保留本地脏状态，成功确认后才清脏。短篇没有云端记录时返回明确空状态，不把缺失进度当作接口成功数据。
- 章评复用公共评论缓存、章末标记与列表。评论入口位于正文末尾；回复使用独立范围缓存。关闭开关或没有可用缓存时，不伪造评论列表。

## 验证与已知限制

- 本次只补文档，没有重新操作真实知乎账号，也没有新建购买、进度或评论写入。
- 对应回归位于 `tests/source/zhihu/`：登录／二维码／安全验证、签名、动态字体、长篇目录、短篇 EPUB、正文布局、阅读进度和章节评论。
- 是否触发安全验证、是否具备付费阅读权限、某章是否有评论，都依赖真实站点与账号；代码分支或离线用例不等于该分支已完成真实账号实测。
- 榜单和搜索当前读取接口首批数据，长篇目录支持分页；不要把目录分页误认为榜单也已支持无限翻页。
- 本 README 描述当前适配能力，不能据此断言知乎其他客户端／接口不存在书架或段落级评论功能。

修改协议、能力或同步语义时，应同时更新本文。
