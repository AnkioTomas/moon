# 知乎盐选

| 能力 | 是否支持 | 备注 |
| --- | --- | --- |
| App 扫码登录 | 支持 | 新会话校验成功后保存 |
| 浏览器登录与 Cookie 导入 | 支持 | 扩展授权或手动粘贴 |
| 设备密码登录 | 不支持 | 其他登录方式交由知乎官网完成 |
| 推荐、榜单与搜索 | 部分支持 | 推荐、热搜及多种盐选榜单；仅首批数据，搜索可能需登录并受风控限制 |
| 详情与评分 | 支持 | 短篇及长篇专栏元数据、评分 |
| 长篇目录 | 支持 | 分页读取并保留章节顺序 |
| 完整正文 | 支持 | 需有效账号及对应权限，恢复动态字体；折叠或未购预览不作完整正文 |
| 短篇阅读 | 支持 | 整篇转为本地 EPUB |
| 章节与全本缓存 | 支持 | 已缓存正文可离线阅读 |
| 云端书架与收藏同步 | 不支持 | 本地书库不代表知乎收藏或购买列表 |
| 远端书架新增与移出 | 不支持 | 本地增删不操作知乎网站内容 |
| 阅读进度同步 | 支持 | 长篇按远端章节及章内比例，短篇按整篇比例 |
| 笔记与统计同步 | 不支持 | 仅本地保存 |
| 整书书评 | 不支持 | 未接入可验证的独立接口 |
| 章评 | 支持 | 真正绑定盐选章节，章末入口、分页和缓存；开关仍叫「显示段评」 |
| 段评 | 不支持 | 评论没有段落定位依据 |
| 评论回复 | 支持 | 支持分页和独立缓存 |
| 评论写操作 | 不支持 | 不发评、不点赞、不删评 |
| 账号切换 | 不支持直接隔离 | 须先退出清理旧数据，未同步记录会丢失 |
